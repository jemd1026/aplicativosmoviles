1. Preparar el proyecto

Trabaja en el proyecto Grid View con el paquete com.example.gridview. Las prácticas principales reutilizan MainActivity y activity_main.xml; los layouts de cada celda y los datos se agregan según el ejercicio.

Organización de las prácticas: crea el paquete adapter para separar ColorAdapter cuando llegues a la Parte 6. Las demás prácticas usan ArrayAdapter y pueden resolverse directamente en MainActivity.kt.
Antes de ejecutar: establece MainActivity como actividad de inicio en AndroidManifest.xml. Si implementas la navegación con Intent, crea y registra también DetalleActivity. El layout de galería usa CardView; si tu proyecto aún no incluye la librería, agrega implementation("androidx.cardview:cardview:1.0.0") en las dependencias del módulo app.

1.1 Crear el proyecto Android

  1. En Android Studio, selecciona New Project → Empty Views Activity.
  2. En Name, escribe Grid View.
  3. En Package name, establece com.example.gridview.
  4. Selecciona Kotlin como lenguaje y pulsa Finish.
Importante: el nombre del proyecto puede llevar un espacio; el paquete debe escribirse sin espacios y exactamente como com.example.gridview. Android Studio usará este paquete como base de las rutas y declaraciones package de los ejemplos.

📚 PARTE 1: ¿Qué es GridView?

Definición

GridView es un componente de Android que muestra elementos en una cuadrícula bidimensional desplazable (filas y columnas). Es ideal para presentar colecciones de datos de forma visual, como galerías de fotos, catálogos de productos, iconos de aplicaciones, etc.

✅ ¿Cuándo usar GridView?

  • 📸 Galerías de imágenes: Fotos, avatares, miniaturas
  • 🛍️ Catálogos de productos: Tiendas online, e-commerce
  • 🎯 Menús visuales: Aplicaciones, categorías, opciones
  • 📱 Iconos de apps: Launchers, organizadores
  • 🎨 Paletas de colores: Selectores, editores
  • 🔢 Calculadoras: Teclados numéricos
  • 📅 Calendarios: Vista mensual
  • 🎲 Juegos: Tableros, mosaicos

❌ ¿Cuándo NO usar GridView?

  • 📝 Listas largas de texto: Mejor ListView
  • 📊 Datos tabulares complejos: Mejor TableLayout
  • 🔄 Items de diferentes tamaños: Mejor RecyclerView con StaggeredGrid
  • ⚡ Listas muy grandes (>1000 items): Mejor RecyclerView por rendimiento

🆚 GridView vs Otros Componentes

GridView:

Cuadrícula simple, múltiples columnas, todos los items del mismo tamaño

ListView:

Lista vertical, una columna, mejor para texto

RecyclerView + GridLayoutManager:

Más eficiente, mayor flexibilidad, recomendado para proyectos nuevos

💡 Ventajas del GridView:
  • ✅ Fácil de implementar (más simple que RecyclerView)
  • ✅ Perfecto para galerías de imágenes
  • ✅ Diseño visual atractivo
  • ✅ Aprovecha mejor el espacio horizontal
  • ✅ Ideal para items cuadrados o uniformes
⚠️ Limitaciones:
  • ❌ Todos los items deben tener el mismo tamaño
  • ❌ Solo scroll vertical (no horizontal)
  • ❌ Menos eficiente que RecyclerView para listas grandes
  • ❌ ViewHolder opcional (afecta rendimiento)

📝 Atributos importantes del GridView:
  • numColumns → Número de columnas (ej: 2, 3, 4, auto_fit)
  • horizontalSpacing → Espacio horizontal entre items
  • verticalSpacing → Espacio vertical entre items
  • stretchMode → Cómo se estiran las columnas
  • columnWidth → Ancho de cada columna (cuando usas auto_fit)

💻 Paso 2: MainActivity con Datos Simples

📱 MainActivity.kt (Con ArrayAdapter simple)

package com.example.gridview

import android.os.Bundle
import android.widget.ArrayAdapter
import android.widget.GridView
import android.widget.Toast
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)
        
        // 1. Referenciar el GridView
        val gridView = findViewById<GridView>(R.id.gridView)
        
        // 2. Datos hardcoded
        val emojis = arrayOf(
            "😀", "😃", "😄", "😁", "😆",
            "😅", "😂", "🤣", "😊", "😇",
            "🙂", "🙃", "😉", "😌", "😍",
            "🥰", "😘", "😗", "😙", "😚"
        )
        
        // 3. Crear adapter
        val adapter = ArrayAdapter(
            this,
            android.R.layout.simple_list_item_1,
            emojis
        )
        
        // 4. Conectar adapter con GridView
        gridView.adapter = adapter
        
        // 5. Agregar listener de click
        gridView.setOnItemClickListener { parent, view, position, id ->
            Toast.makeText(
                this,
                "Seleccionaste: ${emojis[position]}",
                Toast.LENGTH_SHORT
            ).show()
        }
    }
}
💡 Resultado:

Este código crea un GridView de 3 columnas con emojis. Al hacer click en cualquier emoji, muestra un Toast con el emoji seleccionado.

<GridView
    android:numColumns="3"/>

<!-- 4 columnas -->
<GridView
    android:numColumns="4"/>

💻 Método 2: Auto Fit (Ajuste Automático)

📄 XML - Columnas automáticas

<GridView
    android:id="@+id/gridView"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:numColumns="auto_fit"
    android:columnWidth="100dp"
    android:horizontalSpacing="8dp"
    android:verticalSpacing="8dp"
    android:stretchMode="columnWidth"/>
📝 auto_fit:

Con numColumns="auto_fit" y columnWidth="100dp", el GridView calcula automáticamente cuántas columnas caben según el ancho de la pantalla.

Ventaja: Se adapta a diferentes tamaños de pantalla (teléfonos, tablets)

💻 Modos de Estiramiento (stretchMode)

📄 Opciones de stretchMode

<!-- Estirar ancho de columnas -->
android:stretchMode="columnWidth"

<!-- Estirar espaciado entre columnas -->
android:stretchMode="spacingWidth"

<!-- Estirar espaciado con ancho uniforme -->
android:stretchMode="spacingWidthUniform"

<!-- No estirar -->
android:stretchMode="none"
💡 Recomendación:

Usa stretchMode="columnWidth" para la mayoría de casos. Las columnas se ajustarán al espacio disponible.

📱 MainActivity.kt (Con cambio de categorías)

class MainActivity : AppCompatActivity() {
    
    private lateinit var gridView: GridView
    private lateinit var tvCategoria: TextView
    
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)
        
        gridView = findViewById(R.id.gridView)
        tvCategoria = findViewById(R.id.tvCategoria)
        val btnAnimales = findViewById<Button>(R.id.btnAnimales)
        val btnFrutas = findViewById<Button>(R.id.btnFrutas)
        val btnDeportes = findViewById<Button>(R.id.btnDeportes)
        
        // Botón Animales
        btnAnimales.setOnClickListener {
            cargarCategoria("Animales", R.array.animales)
        }
        
        // Botón Frutas
        btnFrutas.setOnClickListener {
            cargarCategoria("Frutas", R.array.frutas)
        }
        
        // Botón Deportes
        btnDeportes.setOnClickListener {
            cargarCategoria("Deportes", R.array.deportes)
        }
        
        // Cargar animales por defecto
        cargarCategoria("Animales", R.array.animales)
    }
    
    private fun cargarCategoria(nombre: String, arrayId: Int) {
        tvCategoria.text = "Categoría: $nombre"
        
        val items = resources.getStringArray(arrayId)
        
        val adapter = ArrayAdapter(
            this,
            android.R.layout.simple_list_item_1,
            items
        )
        
        gridView.adapter = adapter
        
        gridView.setOnItemClickListener { parent, view, position, id ->
            Toast.makeText(
                this,
                "$nombre: ${items[position]}",
                Toast.LENGTH_SHORT
            ).show()
        }
    }
}

⚡ PARTE 5: Eventos y Clicks

📚 OnItemClickListener

GridView usa el mismo listener que ListView para detectar clicks en los items.

💻 Click Simple con Toast

📱 Click básico

gridView.setOnItemClickListener { parent, view, position, id ->
    val item = items[position]
    Toast.makeText(this, "Seleccionaste: $item", Toast.LENGTH_SHORT).show()
}

💻 Click con AlertDialog

📱 Mostrar información detallada

import androidx.appcompat.app.AlertDialog

gridView.setOnItemClickListener { parent, view, position, id ->
    val item = items[position]
    
    AlertDialog.Builder(this)
        .setTitle("Item Seleccionado")
        .setMessage("Posición: $position\nItem: $item")
        .setPositiveButton("OK", null)
        .show()
}

💻 Long Click (Mantener Presionado)

📱 OnItemLongClickListener

gridView.setOnItemLongClickListener { parent, view, position, id ->
    val item = items[position]
    
    AlertDialog.Builder(this)
        .setTitle("Opciones")
        .setMessage("¿Qué deseas hacer con $item?")
        .setPositiveButton("Compartir") { dialog, which ->
            // Acción compartir
            Toast.makeText(this, "Compartir: $item", Toast.LENGTH_SHORT).show()
        }
        .setNegativeButton("Cancelar", null)
        .show()
    
    true // Retornar true para consumir el evento
}

💻 Pasar Datos a Otra Activity

📱 Navegación con Intent

gridView.setOnItemClickListener { parent, view, position, id ->
    val item = items[position]
    
    // Crear Intent
    val intent = Intent(this, DetalleActivity::class.java)
    intent.putExtra("ITEM", item)
    intent.putExtra("POSICION", position)
    
    // Iniciar Activity
    startActivity(intent)
}

📱 ColorAdapter.kt

class ColorAdapter(
    private val context: Context,
    private val colores: IntArray
) : BaseAdapter() {

    override fun getCount(): Int = colores.size

    override fun getItem(position: Int): Any = colores[position]

    override fun getItemId(position: Int): Long = position.toLong()

    override fun getView(position: Int, convertView: View?, parent: ViewGroup?): View {
        val view = View(context)
        view.layoutParams = ViewGroup.LayoutParams(200, 200)
        view.setBackgroundColor(colores[position])
        return view
    }
}

💻 Ejemplo 4: Teclado Numérico

📱 MainActivity.kt

class MainActivity : AppCompatActivity() {
    
    private lateinit var tvDisplay: TextView
    
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)
        
        val gridView = findViewById<GridView>(R.id.gridView)
        tvDisplay = findViewById(R.id.tvDisplay)
        
        // Teclado numérico
        val teclas = arrayOf(
            "1", "2", "3",
            "4", "5", "6",
            "7", "8", "9",
            "⌫", "0", "✓"
        )
        
        val adapter = ArrayAdapter(
            this,
            android.R.layout.simple_list_item_1,
            teclas
        )
        
        gridView.adapter = adapter
        
        gridView.setOnItemClickListener { parent, view, position, id ->
            val tecla = teclas[position]
            val textoActual = tvDisplay.text.toString()
            
            when (tecla) {
                "⌫" -> {
                    if (textoActual.isNotEmpty()) {
                        tvDisplay.text = textoActual.dropLast(1)
                    }
                }
                "✓" -> {
                    Toast.makeText(this, "Número: $textoActual", Toast.LENGTH_SHORT).show()
                }
                else -> {
                    tvDisplay.text = textoActual + tecla
                }
            }
        }
    }
}
