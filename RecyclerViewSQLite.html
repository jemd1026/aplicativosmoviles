RecyclerView con SQLite en Android

Una lista que guarda sus datos en una base de datos local. Todo el proyecto se desarrolla en el paquete com.example.recyclerviewsqlite, con la actividad MainActivity y el layout activity_main.xml.

1. Preparar el proyecto

1.1 Crear el proyecto

  1. En Android Studio: File → New → New Project → Empty Views Activity.
  2. Name: RecyclerViewSQLite. Package name: com.example.recyclerviewsqlite.
  3. Language: Kotlin. Pulsa Finish. El asistente crea MainActivity.kt y activity_main.xml, y ya la registra como actividad de inicio en el manifiesto.

1.2 Dependencias

La plantilla ya incluye Material (necesario para el FloatingActionButton) y ConstraintLayout. Agrega RecyclerView de forma explícita en build.gradle.kts (Module :app) y pulsa Sync Now:

dependencies {
    implementation("androidx.recyclerview:recyclerview:1.3.2")

    // ... dependencias generadas por la plantilla ...
}

1.3 Estructura del proyecto

Organiza el código en capas desde el inicio. Primero se trabaja con la tabla producto_categoria; la tabla producto se agregará después en el mismo proyecto.

app/src/main │ ├── java/com/example/recyclerviewsqlite │ ├── MainActivity.kt ← orquesta la pantalla │ ├── model/ │ │ └── ProductoCategoria.kt ← Parte 4 │ ├── data/ │ │ └── ProductoCategoriaDbHelper.kt ← Parte 4 (se amplía en 5 y 6) │ └── adapter/ │ └── ProductoCategoriaAdapter.kt ← Parte 5 (se amplía en 6) │ ├── res/layout │ ├── activity_main.xml ← se actualiza en 5, 6 y 7 │ ├── item_producto_categoria.xml ← Parte 5 │ └── dialog_producto_categoria.xml ← Parte 6 │ └── AndroidManifest.xml
Crear un subpaquete: clic derecho en com.example.recyclerviewsqlite → New → Package → escribe model, data o adapter. Después, clic derecho en el subpaquete → New → Kotlin Class/File.
Importante: cuando una parte indique «reemplazar», copia el bloque completo con el botón Copiar y sustituye todo el contenido del archivo. Así evitas mezclar fragmentos de versiones distintas.

2. Temario y objetivo

Vas a conectar una lista moderna de Android con una base de datos local SQLite. Los datos dejan de ser estáticos: se guardan en el dispositivo y sobreviven al cierre de la app.

05

06

4.2 Helper ProductoCategoriaDbHelper

Clic derecho en el paquete data → New → Kotlin Class/File → ProductoCategoriaDbHelper.

package com.example.recyclerviewsqlite.data

import android.content.Context
import android.database.sqlite.SQLiteDatabase
import android.database.sqlite.SQLiteOpenHelper
import android.util.Log

// Administra la base de datos local SQLite:
// nombre de la BD, versión y tabla principal.
class ProductoCategoriaDbHelper(context: Context) :
    SQLiteOpenHelper(context, DB_NAME, null, DB_VERSION) {

    companion object {
        // Etiqueta para identificar los mensajes en Logcat.
        const val TAG = "DBProductCat"

        // Nombre del archivo físico de la base de datos en el dispositivo.
        const val DB_NAME = "inventario.db"

        // Versión de la BD. Si cambia la estructura, este número
        // debe aumentar para que se ejecute onUpgrade().
        const val DB_VERSION = 1

        // Nombre de la tabla y de sus columnas.
        const val TABLE_CATEGORIA = "producto_categoria"
        const val COL_CAT_ID = "id"
        const val COL_CAT_NOMBRE = "nombre"
        const val COL_CAT_DESCRIPCION = "descripcion"
    }

    override fun onCreate(db: SQLiteDatabase) {
        // Sentencia SQL que crea la tabla producto_categoria.
        // trimIndent() quita la sangría sobrante de cada línea.
        val createCategoriaTable = """
            CREATE TABLE $TABLE_CATEGORIA (
                $COL_CAT_ID INTEGER PRIMARY KEY AUTOINCREMENT,
                $COL_CAT_NOMBRE TEXT NOT NULL,
                $COL_CAT_DESCRIPCION TEXT NOT NULL
            )
        """.trimIndent()

        Log.d(TAG, "onCreate(): se está creando la tabla $TABLE_CATEGORIA")

        // Ejecuta la instrucción SQL para crear la tabla.
        db.execSQL(createCategoriaTable)

        Log.d(TAG, "onCreate(): tabla $TABLE_CATEGORIA creada correctamente")
    }

    override fun onUpgrade(db: SQLiteDatabase, oldVersion: Int, newVersion: Int) {
        // Si la versión cambia, se elimina la tabla anterior
        // y se vuelve a crear con la nueva estructura.
        Log.d(TAG, "onUpgrade(): versión antigua = $oldVersion, versión nueva = $newVersion")
        db.execSQL("DROP TABLE IF EXISTS $TABLE_CATEGORIA")
        onCreate(db)
    }
}

4.3 Crear la base de datos desde MainActivity

La tabla no se crea solo por escribir la clase. SQLite construye la base de datos cuando se crea una instancia del helper y se abre la conexión:

package com.example.recyclerviewsqlite

import android.os.Bundle
import android.util.Log
import androidx.activity.enableEdgeToEdge
import androidx.appcompat.app.AppCompatActivity
import androidx.core.view.ViewCompat
import androidx.core.view.WindowInsetsCompat
import com.example.recyclerviewsqlite.data.ProductoCategoriaDbHelper

class MainActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        enableEdgeToEdge()
        setContentView(R.layout.activity_main)

        ViewCompat.setOnApplyWindowInsetsListener(findViewById(R.id.main)) { v, insets ->
            val systemBars = insets.getInsets(WindowInsetsCompat.Type.systemBars())
            v.setPadding(systemBars.left, systemBars.top, systemBars.right, systemBars.bottom)
            insets
        }

        // Se crea el helper de SQLite.
        Log.d("DBProductCat", "MainActivity: se crea la instancia del helper")
        val dbHelper = ProductoCategoriaDbHelper(this)

        // Al abrir la base de datos, Android crea inventario.db
        // y ejecuta onCreate() si todavía no existe.
        Log.d("DBProductCat", "MainActivity: se solicita writableDatabase")
        val db = dbHelper.writableDatabase
        Log.d("DBProductCat", "MainActivity: la base de datos está lista para usarse")

        // Se cierra la conexión después de esta prueba inicial.
        db.close()
        Log.d("DBProductCat", "MainActivity: conexión cerrada")
    }
}

onCreate(): se está creando la tabla producto_categoria

5.1 Agregar obtenerCategorias() al helper

Reemplaza todo el contenido de ProductoCategoriaDbHelper.kt:

package com.example.recyclerviewsqlite.data

import android.content.Context
import android.database.sqlite.SQLiteDatabase
import android.database.sqlite.SQLiteOpenHelper
import android.util.Log
import com.example.recyclerviewsqlite.model.ProductoCategoria

class ProductoCategoriaDbHelper(context: Context) :
    SQLiteOpenHelper(context, DB_NAME, null, DB_VERSION) {

    companion object {
        const val TAG = "DBProductCat"
        const val DB_NAME = "inventario.db"
        const val DB_VERSION = 1

        const val TABLE_CATEGORIA = "producto_categoria"
        const val COL_CAT_ID = "id"
        const val COL_CAT_NOMBRE = "nombre"
        const val COL_CAT_DESCRIPCION = "descripcion"
    }

    override fun onCreate(db: SQLiteDatabase) {
        val createCategoriaTable = """
            CREATE TABLE $TABLE_CATEGORIA (
                $COL_CAT_ID INTEGER PRIMARY KEY AUTOINCREMENT,
                $COL_CAT_NOMBRE TEXT NOT NULL,
                $COL_CAT_DESCRIPCION TEXT NOT NULL
            )
        """.trimIndent()

        Log.d(TAG, "onCreate(): se está creando la tabla $TABLE_CATEGORIA")
        db.execSQL(createCategoriaTable)
        Log.d(TAG, "onCreate(): tabla $TABLE_CATEGORIA creada correctamente")
    }

    override fun onUpgrade(db: SQLiteDatabase, oldVersion: Int, newVersion: Int) {
        Log.d(TAG, "onUpgrade(): versión antigua = $oldVersion, versión nueva = $newVersion")
        db.execSQL("DROP TABLE IF EXISTS $TABLE_CATEGORIA")
        onCreate(db)
    }

    fun obtenerCategorias(): MutableList<ProductoCategoria> {
        // Lista donde se guardan los resultados.
        val listaCategorias = mutableListOf<ProductoCategoria>()

        // Se abre la base de datos en modo lectura.
        val db = readableDatabase

        // Consulta SQL: todas las categorías ordenadas por id.
        val query = "SELECT * FROM $TABLE_CATEGORIA ORDER BY $COL_CAT_ID ASC"

        // Cursor: permite recorrer el resultado fila por fila.
        val cursor = db.rawQuery(query, null)

        Log.d(TAG, "obtenerCategorias(): total recuperado = ${cursor.count}")

        // moveToFirst() verifica si existe al menos un registro.
        if (cursor.moveToFirst()) {
            do {
                // Se leen las columnas de la fila actual.
                val id = cursor.getInt(cursor.getColumnIndexOrThrow(COL_CAT_ID))
                val nombre = cursor.getString(cursor.getColumnIndexOrThrow(COL_CAT_NOMBRE))
                val descripcion = cursor.getString(cursor.getColumnIndexOrThrow(COL_CAT_DESCRIPCION))

                // Cada fila se convierte en un objeto y se agrega a la lista.
                listaCategorias.add(ProductoCategoria(id, nombre, descripcion))
            } while (cursor.moveToNext())
        }

        // Siempre se cierra el cursor y la conexión al terminar.
        cursor.close()
        db.close()

        return listaCategorias
    }
}
Método del Cursor Función
moveToFirst() Se ubica en la primera fila; devuelve false si no hay registros.
moveToNext() Avanza a la siguiente fila; devuelve false al llegar al final.
getColumnIndexOrThrow("col") Obtiene la posición de la columna por su nombre.
getInt() / getString() Lee el valor de la columna en la fila actual.
close() Libera los recursos del cursor.

package com.example.recyclerviewsqlite.adapter

import android.view.LayoutInflater
import android.view.View
import android.view.ViewGroup
import android.widget.TextView
import androidx.recyclerview.widget.RecyclerView
import com.example.recyclerviewsqlite.R
import com.example.recyclerviewsqlite.model.ProductoCategoria

class ProductoCategoriaAdapter(
    private val listaCategorias: MutableList<ProductoCategoria>
) : RecyclerView.Adapter<ProductoCategoriaAdapter.ProductoCategoriaViewHolder>() {

    // ViewHolder: guarda las referencias de los controles de cada fila.
    class ProductoCategoriaViewHolder(itemView: View) : RecyclerView.ViewHolder(itemView) {
        val tvNombreCategoria: TextView = itemView.findViewById(R.id.tvNombreCategoria)
        val tvDescripcionCategoria: TextView = itemView.findViewById(R.id.tvDescripcionCategoria)
    }

    override fun onCreateViewHolder(parent: ViewGroup, viewType: Int): ProductoCategoriaViewHolder {
        // Infla item_producto_categoria.xml para convertirlo en una vista real.
        val view = LayoutInflater.from(parent.context)
            .inflate(R.layout.item_producto_categoria, parent, false)

        return ProductoCategoriaViewHolder(view)
    }

    override fun onBindViewHolder(holder: ProductoCategoriaViewHolder, position: Int) {
        // Objeto de la posición actual.
        val categoria = listaCategorias[position]

        // Coloca los datos en los TextView de la fila.
        holder.tvNombreCategoria.text = categoria.nombre
        holder.tvDescripcionCategoria.text = categoria.descripcion
    }

    // Cuántas filas se deben mostrar.
    override fun getItemCount(): Int = listaCategorias.size
}

5.5 Leer la BD y mostrarla en MainActivity

Reemplaza todo el contenido de MainActivity.kt:

package com.example.recyclerviewsqlite

import android.os.Bundle
import android.util.Log
import android.view.View
import android.widget.TextView
import androidx.activity.enableEdgeToEdge
import androidx.appcompat.app.AppCompatActivity
import androidx.core.view.ViewCompat
import androidx.core.view.WindowInsetsCompat
import androidx.recyclerview.widget.LinearLayoutManager
import androidx.recyclerview.widget.RecyclerView
import com.example.recyclerviewsqlite.adapter.ProductoCategoriaAdapter
import com.example.recyclerviewsqlite.data.ProductoCategoriaDbHelper
import com.example.recyclerviewsqlite.model.ProductoCategoria

class MainActivity : AppCompatActivity() {

    private lateinit var recyclerCategorias: RecyclerView
    private lateinit var tvSinDatos: TextView
    private lateinit var dbHelper: ProductoCategoriaDbHelper
    private lateinit var adapter: ProductoCategoriaAdapter
    private val listaCategorias = mutableListOf<ProductoCategoria>()

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        enableEdgeToEdge()
        setContentView(R.layout.activity_main)

        ViewCompat.setOnApplyWindowInsetsListener(findViewById(R.id.main)) { v, insets ->
            val systemBars = insets.getInsets(WindowInsetsCompat.Type.systemBars())
            v.setPadding(systemBars.left, systemBars.top, systemBars.right, systemBars.bottom)
            insets
        }

        // Referencias a los controles del layout.
        recyclerCategorias = findViewById(R.id.recyclerCategorias)
        tvSinDatos = findViewById(R.id.tvSinDatos)

        // Se crean el helper y el adapter.
        dbHelper = ProductoCategoriaDbHelper(this)
        adapter = ProductoCategoriaAdapter(listaCategorias)

        // Lista vertical.
        recyclerCategorias.layoutManager = LinearLayoutManager(this)
        recyclerCategorias.adapter = adapter

        // Se cargan los registros guardados en SQLite.
        cargarCategorias()
    }

    private fun cargarCategorias() {
        // Se limpia la lista para evitar duplicados al recargar.
        listaCategorias.clear()

        // Se agregan todos los registros recuperados de SQLite.
        listaCategorias.addAll(dbHelper.obtenerCategorias())

        Log.d("DBProductCat", "MainActivity: categorías cargadas = ${listaCategorias.size}")

        // Notifica al adapter para que vuelva a dibujar la lista.
        adapter.notifyDataSetChanged()

        // Sin datos: se muestra el mensaje; con datos: se muestra la lista.
        if (listaCategorias.isEmpty()) {
            tvSinDatos.visibility = View.VISIBLE
            recyclerCategorias.visibility = View.GONE
        } else {
            tvSinDatos.visibility = View.GONE
            recyclerCategorias.visibility = View.VISIBLE
        }
    }
}
La misma lista: el Adapter recibe listaCategorias por referencia. cargarCategorias() modifica esa misma lista (clear() + addAll()), por eso basta con notifyDataSetChanged() para redibujar.
Si la lista no aparece, revisa:
  • Que la tabla producto_categoria tenga registros (Parte 4.5).
  • Que el RecyclerView tenga asignado un LayoutManager.
  • Que los ids del XML coincidan con los de findViewById().

6.3 Helper con los métodos CRUD

Reemplaza ProductoCategoriaDbHelper.kt:

package com.example.recyclerviewsqlite.data

import android.content.ContentValues
import android.content.Context
import android.database.sqlite.SQLiteDatabase
import android.database.sqlite.SQLiteOpenHelper
import android.util.Log
import com.example.recyclerviewsqlite.model.ProductoCategoria

class ProductoCategoriaDbHelper(context: Context) :
    SQLiteOpenHelper(context, DB_NAME, null, DB_VERSION) {

    companion object {
        const val TAG = "DBProductCat"
        const val DB_NAME = "inventario.db"
        const val DB_VERSION = 1

        const val TABLE_CATEGORIA = "producto_categoria"
        const val COL_CAT_ID = "id"
        const val COL_CAT_NOMBRE = "nombre"
        const val COL_CAT_DESCRIPCION = "descripcion"
    }

    override fun onCreate(db: SQLiteDatabase) {
        val createCategoriaTable = """
            CREATE TABLE $TABLE_CATEGORIA (
                $COL_CAT_ID INTEGER PRIMARY KEY AUTOINCREMENT,
                $COL_CAT_NOMBRE TEXT NOT NULL,
                $COL_CAT_DESCRIPCION TEXT NOT NULL
            )
        """.trimIndent()

        Log.d(TAG, "onCreate(): se está creando la tabla $TABLE_CATEGORIA")
        db.execSQL(createCategoriaTable)
        Log.d(TAG, "onCreate(): tabla $TABLE_CATEGORIA creada correctamente")
    }

    override fun onUpgrade(db: SQLiteDatabase, oldVersion: Int, newVersion: Int) {
        Log.d(TAG, "onUpgrade(): versión antigua = $oldVersion, versión nueva = $newVersion")
        db.execSQL("DROP TABLE IF EXISTS $TABLE_CATEGORIA")
        onCreate(db)
    }

    // CREATE
    fun insertarCategoria(categoria: ProductoCategoria): Long {
        // Se abre la BD en modo escritura.
        val db = writableDatabase

        // ContentValues guarda cada campo como par columna-valor.
        val values = ContentValues().apply {
            put(COL_CAT_NOMBRE, categoria.nombre)
            put(COL_CAT_DESCRIPCION, categoria.descripcion)
        }

        // insert() devuelve el id generado o -1 si ocurre un error.
        val resultado = db.insert(TABLE_CATEGORIA, null, values)
        Log.d(TAG, "insertarCategoria(): resultado = $resultado")

        db.close()
        return resultado
    }

    // READ
    fun obtenerCategorias(): MutableList<ProductoCategoria> {
        val listaCategorias = mutableListOf<ProductoCategoria>()
        val db = readableDatabase
        val query = "SELECT * FROM $TABLE_CATEGORIA ORDER BY $COL_CAT_ID ASC"
        val cursor = db.rawQuery(query, null)

        Log.d(TAG, "obtenerCategorias(): total recuperado = ${cursor.count}")

        if (cursor.moveToFirst()) {
            do {
                val id = cursor.getInt(cursor.getColumnIndexOrThrow(COL_CAT_ID))
                val nombre = cursor.getString(cursor.getColumnIndexOrThrow(COL_CAT_NOMBRE))
                val descripcion = cursor.getString(cursor.getColumnIndexOrThrow(COL_CAT_DESCRIPCION))
                listaCategorias.add(ProductoCategoria(id, nombre, descripcion))
            } while (cursor.moveToNext())
        }

        cursor.close()
        db.close()
        return listaCategorias
    }

    // UPDATE
    fun actualizarCategoria(categoria: ProductoCategoria): Int {
        val db = writableDatabase
        val values = ContentValues().apply {
            put(COL_CAT_NOMBRE, categoria.nombre)
            put(COL_CAT_DESCRIPCION, categoria.descripcion)
        }

        // update() devuelve cuántas filas fueron modificadas.
        val resultado = db.update(
            TABLE_CATEGORIA,
            values,
            "$COL_CAT_ID = ?",
            arrayOf(categoria.id.toString())
        )

        Log.d(TAG, "actualizarCategoria(): filas afectadas = $resultado")
        db.close()
        return resultado
    }

    // DELETE
    fun eliminarCategoria(id: Int): Int {
        val db = writableDatabase

        // delete() devuelve cuántas filas fueron eliminadas.
        val resultado = db.delete(
            TABLE_CATEGORIA,
            "$COL_CAT_ID = ?",
            arrayOf(id.toString())
        )

        Log.d(TAG, "eliminarCategoria(): filas afectadas = $resultado")
        db.close()
        return resultado
    }
}
Método SQL equivalente Devuelve
db.insert() INSERT INTO … VALUES (…) id generado, o -1 si falla
db.rawQuery() SELECT … Un Cursor
db.update() UPDATE … SET … WHERE id = ? Filas modificadas
db.delete() DELETE FROM … WHERE id = ? Filas eliminadas
El signo ?: es un parámetro. El valor real se pasa aparte en arrayOf(...), lo que evita errores de comillas e inyección SQL.

                    Toast.makeText(this, "Categoría registrada", Toast.LENGTH_SHORT).show()
                    cargarCategorias()

        etNombreCategoria.setText(categoria.nombre)

            .setTitle("Editar categoría")
            .setView(view)
            .setPositiveButton("Actualizar") { _, _ ->
                val nombre = etNombreCategoria.text.toString().trim()
                val descripcion = etDescripcionCategoria.text.toString().trim()

                if (nombre.isEmpty() || descripcion.isEmpty()) {
                    Toast.makeText(this, "Completa todos los campos", Toast.LENGTH_SHORT).show()
                    return@setPositiveButton
                }

                // Se conserva el id original y se cambian los demás campos.
                val categoriaActualizada = categoria.copy(nombre = nombre, descripcion = descripcion)
                val resultado = dbHelper.actualizarCategoria(categoriaActualizada)

                if (resultado > 0) {
                    Toast.makeText(this, "Categoría actualizada", Toast.LENGTH_SHORT).show()
                    cargarCategorias()

            }
            .setNegativeButton("Cancelar", null)
            .show()
    }

return@setPositiveButton: sale solo de la lambda del botón (no de la función completa). Se usa para detener el guardado cuando la validación falla.
Acción del usuario Secuencia
Pulsar «Agregar categoría» Diálogo → validar → insertarCategoria() → cargarCategorias()
Tocar una fila Diálogo con datos → validar → actualizarCategoria() → cargarCategorias()
Mantener presionada una fila Confirmación → eliminarCategoria() → cargarCategorias()
Errores comunes:
  • Olvidar llamar a cargarCategorias() después de insertar, actualizar o eliminar.
  • Guardar con campos vacíos.
  • No pasar las funciones onClick y onLongClick al adapter.
  • Cambiar los ids del layout sin actualizar los findViewById().

        // Se vuelve a aplicar el filtro para no perder la búsqueda activa.
        filtrarCategorias(etBuscarCategoria.text.toString())
    }

    private fun filtrarCategorias(texto: String) {
        listaCategorias.clear()

        if (texto.isBlank()) {
            // Buscador vacío: se muestran todos los registros.
            listaCategorias.addAll(listaCategoriasCompleta)
        } else {
            // Se filtra por nombre ignorando mayúsculas y minúsculas.
            for (categoria in listaCategoriasCompleta) {
                if (categoria.nombre.contains(texto, ignoreCase = true)) {
                    listaCategorias.add(categoria)
                }
            }
        }

        adapter.notifyDataSetChanged()
        actualizarEstadoLista(texto)
    }

    private fun actualizarEstadoLista(textoBusqueda: String) {
        // Caso 1: la BD no tiene registros.
        if (listaCategoriasCompleta.isEmpty()) {
            tvSinDatos.text = "No hay categorías registradas"
            tvSinDatos.visibility = View.VISIBLE
            recyclerCategorias.visibility = View.GONE
            return
        }

        // Caso 2: hay datos, pero la búsqueda no encuentra coincidencias.
        if (listaCategorias.isEmpty() && textoBusqueda.isNotBlank()) {
            tvSinDatos.text = "No se encontraron categorías"
            tvSinDatos.visibility = View.VISIBLE
            recyclerCategorias.visibility = View.GONE
            return
        }

        // Caso 3: hay registros para mostrar.
        tvSinDatos.visibility = View.GONE
        recyclerCategorias.visibility = View.VISIBLE
    }

    private fun mostrarDialogoAgregar() {
        val view = LayoutInflater.from(this).inflate(R.layout.dialog_producto_categoria, null)
        val etNombreCategoria = view.findViewById<EditText>(R.id.etNombreCategoria)
        val etDescripcionCategoria = view.findViewById<EditText>(R.id.etDescripcionCategoria)

        AlertDialog.Builder(this)
            .setTitle("Agregar categoría")
            .setView(view)
            .setPositiveButton("Guardar") { _, _ ->
                val nombre = etNombreCategoria.text.toString().trim()
                val descripcion = etDescripcionCategoria.text.toString().trim()

                if (nombre.isEmpty() || descripcion.isEmpty()) {
                    Toast.makeText(this, "Completa todos los campos", Toast.LENGTH_SHORT).show()
                    return@setPositiveButton
                }

                val categoria = ProductoCategoria(nombre = nombre, descripcion = descripcion)
                val resultado = dbHelper.insertarCategoria(categoria)

                if (resultado != -1L) {
                    Toast.makeText(this, "Categoría registrada", Toast.LENGTH_SHORT).show()
                    cargarCategorias()
                } else {
                    Toast.makeText(this, "No se pudo registrar", Toast.LENGTH_SHORT).show()
                }
            }
            .setNegativeButton("Cancelar", null)
            .show()
    }

    private fun mostrarDialogoEditar(categoria: ProductoCategoria) {
        val view = LayoutInflater.from(this).inflate(R.layout.dialog_producto_categoria, null)
        val etNombreCategoria = view.findViewById<EditText>(R.id.etNombreCategoria)

            .setPositiveButton("Actualizar") { _, _ ->
                val nombre = etNombreCategoria.text.toString().trim()
                val descripcion = etDescripcionCategoria.text.toString().trim()

                if (nombre.isEmpty() || descripcion.isEmpty()) {
                    Toast.makeText(this, "Completa todos los campos", Toast.LENGTH_SHORT).show()
                    return@setPositiveButton
                }

                val categoriaActualizada = categoria.copy(nombre = nombre, descripcion = descripcion)
                val resultado = dbHelper.actualizarCategoria(categoriaActualizada)

                if (resultado > 0) {
                    Toast.makeText(this, "Categoría actualizada", Toast.LENGTH_SHORT).show()
                    cargarCategorias()
                } else {
                    Toast.makeText(this, "No se pudo actualizar", Toast.LENGTH_SHORT).show()
                }
            }
            .setNegativeButton("Cancelar", null)
            .show()
    }

                if (resultado > 0) {
                    Toast.makeText(this, "Categoría eliminada", Toast.LENGTH_SHORT).show()
                    cargarCategorias()
                } else {
                    Toast.makeText(this, "No se pudo eliminar", Toast.LENGTH_SHORT).show()
                }
            }
            .setNegativeButton("Cancelar", null)
            .show()
    }

8. Buenas prácticas y cierre

Buenas prácticas

  • Cerrar el Cursor y la base de datos al terminar.
  • Validar ids y campos antes de actualizar o eliminar.
  • No escribir SQL dentro del Adapter: el SQL vive en el helper.
  • Usar parámetros ? en lugar de concatenar valores.
  • Aumentar DB_VERSION al cambiar la estructura.

Siguientes pasos

  • Agregar la tabla producto con la clave foránea id_categoria.
  • Ordenar la lista por nombre (ORDER BY nombre).
  • Identificar cuándo conviene migrar de SQLite a Room.
  • Relacionar esta guía con prácticas de persistencia avanzada.
Alternativa más segura para el cursor: cursor.use { ... } cierra el cursor automáticamente incluso si ocurre un error dentro del bloque.
