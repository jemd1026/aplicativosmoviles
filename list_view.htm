Guía práctica

ListView en Android con Kotlin

Todas las prácticas se realizan en la actividad ListViewActivity y su layout activity_list_view.xml, dentro del paquete com.example.spinnerlistrecycler.

1. Preparar el proyecto

Trabaja en el proyecto con el paquete com.example.spinnerlistrecycler. Los archivos utilizados en la guía son:

app/src/main │ ├── java/com/example/spinnerlistrecycler │ ├── MainActivity.kt │ ├── ListViewActivity.kt ← se crea en esta guía │ └── DetalleActivity.kt ← se crea en la Parte 8 │ ├── res/layout │ ├── activity_main.xml │ ├── activity_list_view.xml ← se crea en esta guía │ └── activity_detalle.xml ← se crea en la Parte 8 │ ├── res/values │ └── arrays.xml ← se crea en la Parte 4 │ └── AndroidManifest.xml

1.1 Crear ListViewActivity

  1. En el panel Project, haz clic derecho en el paquete com.example.spinnerlistrecycler.
  2. Selecciona New → Activity → Empty Views Activity.
  3. En Activity Name escribe ListViewActivity. El campo Layout Name se completa como activity_list_view.
  4. Verifica que Language sea Kotlin y pulsa Finish.

1.2 Abrir ListViewActivity al iniciar la app

En AndroidManifest.xml, coloca el intent-filter en ListViewActivity para que la app abra directamente la actividad de la práctica. Si otra actividad (por ejemplo SpinnerActivity) tiene el intent-filter, quítaselo y deja android:exported="false".

<activity
    android:name=".ListViewActivity"
    android:exported="true">
    <intent-filter>
        <action android:name="android.intent.action.MAIN" />
        <category android:name="android.intent.category.LAUNCHER" />
    </intent-filter>
</activity>

<activity
    android:name=".MainActivity"
    android:exported="false" />
Importante: cada práctica reemplaza el contenido completo de activity_list_view.xml y ListViewActivity.kt. Usa el botón Copiar de cada bloque y pega el código en Android Studio.

2. ¿Qué es un ListView?

Un ListView muestra una lista vertical desplazable de elementos. Sirve para presentar colecciones de datos: contactos, mensajes, productos o cualquier información que se lea en forma de lista.

2.1 Componentes principales

ListView

Contenedor visual que muestra los elementos en pantalla.

Adapter

Intermediario que convierte cada dato en una vista (fila).

Fuente de datos

Array, ArrayList, base de datos o recursos XML.

2.2 Flujo de datos

Datos → Adapter → ListView → Pantalla

El adapter toma cada elemento de los datos y crea una vista individual para mostrarlo como una fila del ListView.

3.2 Actividad

package com.example.spinnerlistrecycler

import android.os.Bundle
import android.widget.ArrayAdapter
import android.widget.ListView
import androidx.appcompat.app.AppCompatActivity

class ListViewActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_list_view)

        // 1. Referenciar el ListView
        val listView = findViewById<ListView>(R.id.listView)

        // 2. Datos escritos directamente en el código
        val frutas = arrayOf(
            "🍎 Manzana",
            "🍌 Plátano",
            "🍊 Naranja",
            "🍇 Uva",
            "🍉 Sandía"
        )

        // 3. Crear el adapter
        val adapter = ArrayAdapter(
            this,
            android.R.layout.simple_list_item_1,
            frutas
        )

        // 4. Conectar el adapter con el ListView
        listView.adapter = adapter
    }
}
Claves:
  • El id listView debe coincidir en el XML y en Kotlin.
  • ArrayAdapter recibe tres parámetros: contexto, layout de fila y datos.
  • simple_list_item_1 es el layout más básico: un solo TextView.

El layout de la Parte 3 se mantiene. Solo cambia el origen de los datos:

package com.example.spinnerlistrecycler

import android.os.Bundle
import android.widget.ArrayAdapter
import android.widget.ListView
import androidx.appcompat.app.AppCompatActivity

    <item>🎧 AirPods Pro</item>

    <item>S/. 3,500</item>

El layout de la Parte 3 se mantiene. ArrayAdapter solo llena un TextView, por eso aquí se usa SimpleAdapter:

package com.example.spinnerlistrecycler

import android.os.Bundle
import android.widget.ListView
import android.widget.SimpleAdapter
import androidx.appcompat.app.AppCompatActivity

class ListViewActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_list_view)

        val listView = findViewById<ListView>(R.id.listView)

        val nombres = resources.getStringArray(R.array.productos_nombres)
        val precios = resources.getStringArray(R.array.productos_precios)

        // Combinar ambos arreglos: un HashMap por fila
        val productos = mutableListOf<HashMap<String, String>>()

        for (i in nombres.indices) {
            val producto = HashMap<String, String>()
            producto["nombre"] = nombres[i]
            producto["precio"] = precios[i]
            productos.add(producto)
        }

        // SimpleAdapter: clave del mapa → TextView de la fila
        val adapter = SimpleAdapter(
            this,
            productos,
            android.R.layout.simple_list_item_2,
            arrayOf("nombre", "precio"),
            intArrayOf(android.R.id.text1, android.R.id.text2)
        )

        listView.adapter = adapter
    }
}
Cómo se enlaza: la clave "nombre" se muestra en android.R.id.text1 (título) y "precio" en android.R.id.text2 (subtítulo).

package com.example.spinnerlistrecycler

import android.os.Bundle
import android.widget.ArrayAdapter
import android.widget.Button
import android.widget.ListView
import android.widget.Toast
import androidx.appcompat.app.AppCompatActivity

class ListViewActivity : AppCompatActivity() {

    private lateinit var listView: ListView
    private lateinit var items: Array<String>

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_list_view)

        listView = findViewById(R.id.listView)
        val btnMostrar = findViewById<Button>(R.id.btnMostrar)

        items = resources.getStringArray(R.array.lista_compras)

        val adapter = ArrayAdapter(
            this,
            android.R.layout.simple_list_item_checked,
            items
        )

        listView.adapter = adapter
        listView.choiceMode = ListView.CHOICE_MODE_MULTIPLE

        btnMostrar.setOnClickListener {
            mostrarSeleccionados()
        }
    }

    private fun mostrarSeleccionados() {
        val checked = listView.checkedItemPositions
        val seleccionados = mutableListOf<String>()

        for (i in 0 until checked.size()) {
            if (checked.valueAt(i)) {
                seleccionados.add(items[checked.keyAt(i)])
            }
        }

        if (seleccionados.isEmpty()) {
            Toast.makeText(this, "No hay seleccionados", Toast.LENGTH_SHORT).show()
        } else {
            val lista = seleccionados.joinToString("\n")
            Toast.makeText(this, "Seleccionados:\n$lista", Toast.LENGTH_LONG).show()
        }
    }
}
Elemento Función
choiceMode = CHOICE_MODE_MULTIPLE Permite marcar varias filas.
checkedItemPositions Devuelve un SparseBooleanArray: posición → marcada o no.
keyAt(i) / valueAt(i) Posición de la fila y si está marcada.
Ejercicio: crea una lista de tareas pendientes con marca de verificación. Al pulsar «Contar completadas», muestra cuántas están marcadas.

package com.example.spinnerlistrecycler

import android.os.Bundle
import android.widget.ArrayAdapter
import android.widget.ListView
import androidx.appcompat.app.AlertDialog
import androidx.appcompat.app.AppCompatActivity

class ListViewActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_list_view)

        val listView = findViewById<ListView>(R.id.listView)

        val paises = resources.getStringArray(R.array.paises_nombres)
        val capitales = resources.getStringArray(R.array.paises_capitales)
        val poblaciones = resources.getStringArray(R.array.paises_poblacion)

        val adapter = ArrayAdapter(
            this,
            android.R.layout.simple_list_item_1,
            paises
        )
        listView.adapter = adapter

        // Clic en una fila: mostrar detalles en un AlertDialog
        listView.setOnItemClickListener { _, _, position, _ ->
            val mensaje = "Capital: ${capitales[position]}\nPoblación: ${poblaciones[position]}"

            AlertDialog.Builder(this)
                .setTitle(paises[position])
                .setMessage(mensaje)
                .setPositiveButton("OK", null)
                .setIcon(android.R.drawable.ic_dialog_info)
                .show()
        }
    }
}

Guion bajo _: en Kotlin, _ indica un parámetro de la lambda que no se utiliza.

6.2 Tres formas de obtener la fila tocada

listView.setOnItemClickListener { parent, _, position, _ ->
    // Opción 1: desde el arreglo original
    val item1 = paises[position]

    // Opción 2: desde el parent (el ListView)
    val item2 = parent.getItemAtPosition(position) as String

    // Opción 3: desde el adapter
    val item3 = adapter.getItem(position)
}

7. Eventos con OnItemLongClickListener

Se activa al mantener presionada una fila. Es habitual usarlo para eliminar o editar.

Concepto Detalle
Retornar true El evento se consume; no se ejecuta además el clic normal.
Retornar false El evento continúa propagándose.
ArrayList Un Array tiene tamaño fijo; para eliminar filas se necesita una lista modificable.
adapter.notifyDataSetChanged() Avisa al adapter que los datos cambiaron para redibujar la lista.

7.1 Eliminar filas

<string-array name="lista_tareas">
    <item>📝 Estudiar Android</item>
    <item>🏋️ Ir al gimnasio</item>
    <item>🛒 Comprar víveres</item>
    <item>📚 Leer un libro</item>
    <item>💼 Terminar proyecto</item>

Usa el layout de la Parte 3 (solo el ListView):

package com.example.spinnerlistrecycler

import android.os.Bundle
import android.widget.ArrayAdapter
import android.widget.ListView
import android.widget.Toast
import androidx.appcompat.app.AlertDialog
import androidx.appcompat.app.AppCompatActivity

class ListViewActivity : AppCompatActivity() {

    private lateinit var listView: ListView
    private lateinit var tareas: ArrayList<String>
    private lateinit var adapter: ArrayAdapter<String>

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_list_view)

        listView = findViewById(R.id.listView)

        // Convertir el arreglo en ArrayList para poder modificarlo
        val tareasArray = resources.getStringArray(R.array.lista_tareas)
        tareas = ArrayList(tareasArray.toList())

        adapter = ArrayAdapter(
            this,
            android.R.layout.simple_list_item_1,
            tareas
        )
        listView.adapter = adapter

        // Clic normal: ver la tarea
        listView.setOnItemClickListener { _, _, position, _ ->
            Toast.makeText(this, "Tarea: ${tareas[position]}", Toast.LENGTH_SHORT).show()
        }

        // Clic largo: eliminar la tarea
        listView.setOnItemLongClickListener { _, _, position, _ ->
            eliminarTarea(position)
            true  // Consumir el evento
        }
    }

    private fun eliminarTarea(position: Int) {
        val tarea = tareas[position]

        AlertDialog.Builder(this)
            .setTitle("❌ Eliminar tarea")
            .setMessage("¿Eliminar:\n$tarea?")
            .setPositiveButton("Eliminar") { _, _ ->
                // 1. Eliminar del ArrayList
                tareas.removeAt(position)

                // 2. Notificar el cambio al adapter
                adapter.notifyDataSetChanged()

                Toast.makeText(this, "✅ Tarea eliminada", Toast.LENGTH_SHORT).show()
            }
            .setNegativeButton("Cancelar", null)
            .show()
    }
}
Pasos para eliminar filas:
  1. Convertir el arreglo en lista modificable: ArrayList(array.toList()).
  2. Eliminar de la lista: tareas.removeAt(position).
  3. Actualizar la vista: adapter.notifyDataSetChanged().
Ejercicio avanzado — Menú contextual: al mantener presionada una fila, muestra un diálogo con tres opciones:
  • ✏️ Editar (un EditText dentro de un AlertDialog).
  • ❌ Eliminar.
  • ℹ️ Ver información.

import android.content.Intent
import android.os.Bundle
import android.widget.ArrayAdapter
import android.widget.ListView
import androidx.appcompat.app.AppCompatActivity

class ListViewActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_list_view)

        val listView = findViewById<ListView>(R.id.listView)

        val nombres = resources.getStringArray(R.array.productos_detalle_nombres)
        val precios = resources.getStringArray(R.array.productos_detalle_precios)
        val descripciones = resources.getStringArray(R.array.productos_detalle_descripciones)

        val adapter = ArrayAdapter(
            this,
            android.R.layout.simple_list_item_1,
            nombres
        )
        listView.adapter = adapter

        // Clic en una fila: abrir DetalleActivity
        listView.setOnItemClickListener { _, _, position, _ ->
            // 1. Crear el Intent
            val intent = Intent(this, DetalleActivity::class.java)

            // 2. Adjuntar los datos
            intent.putExtra("NOMBRE", nombres[position])
            intent.putExtra("PRECIO", precios[position])
            intent.putExtra("DESCRIPCION", descripciones[position])

            // 3. Abrir la actividad
            startActivity(intent)
        }
    }
}

import android.widget.Button
import android.widget.TextView
import androidx.appcompat.app.AppCompatActivity

class DetalleActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_detalle)

        val tvNombre = findViewById<TextView>(R.id.tvNombre)
        val tvPrecio = findViewById<TextView>(R.id.tvPrecio)
        val tvDescripcion = findViewById<TextView>(R.id.tvDescripcion)
        val btnVolver = findViewById<Button>(R.id.btnVolver)

        // Recibir los datos del Intent
        val nombre = intent.getStringExtra("NOMBRE")
        val precio = intent.getStringExtra("PRECIO")
        val descripcion = intent.getStringExtra("DESCRIPCION")

        // Mostrar los datos
        tvNombre.text = nombre
        tvPrecio.text = precio
        tvDescripcion.text = descripcion

        // Volver a la lista
        btnVolver.setOnClickListener {
            finish()  // Cierra esta actividad
        }
    }
}

Si creaste DetalleActivity como un archivo Kotlin en lugar de usar el asistente, regístrala manualmente. parentActivityName agrega la flecha de retorno en la barra superior:

<activity
    android:name=".DetalleActivity"
    android:exported="false"
    android:parentActivityName=".ListViewActivity" />
