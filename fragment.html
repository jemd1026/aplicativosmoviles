1.1 Crear el proyecto Android

  1. En Android Studio, selecciona New Project → Empty Views Activity.
  2. En Name, escribe Fragments.
  3. En Package name, establece com.example.fragments.
  4. Selecciona Kotlin como lenguaje y pulsa Finish.
Importante: el paquete debe escribirse exactamente como com.example.fragments. Android Studio lo usará como base de las rutas y declaraciones package de los ejemplos.
Dependencias: verifica que el módulo app incluya AndroidX Fragment y AppCompat, necesarias para androidx.fragment.app.Fragment y AppCompatActivity. Si no están incluidas por la plantilla de Android Studio, agrega las dependencias compatibles con las versiones de AndroidX de tu proyecto y sincroniza Gradle.
Importante: activity_main.xml cambia según la práctica: en la Parte 2 contiene un único contenedor; en el ejemplo Master-Detail para tablet contiene dos contenedores, uno para la lista y otro para el detalle. Usa el layout correspondiente al ejemplo que estés implementando.

📚 PARTE 1: ¿Qué son los Fragments?

Definición

Un Fragment es una porción modular de la interfaz de usuario que representa una parte reutilizable de una Activity. Piensa en ellos como "mini-Activities" que pueden ser combinados, reutilizados y que tienen su propio ciclo de vida.

🖼️ Analogía Visual

Activity = Casa completa

Fragments = Habitaciones dentro de la casa

┌─────────────────────────────┐
│      Activity (Casa)        │
│  ┌──────────┐  ┌──────────┐ │
│  │Fragment1 │  │Fragment2 │ │
│  │ (Sala)   │  │ (Cocina) │ │
│  └──────────┘  └──────────┘ │
│  ┌─────────────────────────┐│
│  │    Fragment3 (Comedor)  ││
│  └─────────────────────────┘│
└─────────────────────────────┘

✅ Ventajas de usar Fragments

  • 📱 Modularidad: Divide tu UI en componentes reutilizables
  • 🔄 Reutilización: Usa el mismo Fragment en múltiples Activities
  • 📐 Layouts adaptativos: Diferentes diseños para tablets y móviles
  • ⚡ Transiciones suaves: Cambio de contenido sin cambiar Activity
  • 💾 Ciclo de vida propio: Gestionan su estado independientemente
  • 🗂️ BackStack: Navegación con botón atrás entre Fragments

❌ ¿Cuándo NO usar Fragments?

  • 📄 UI muy simple: Una sola pantalla estática
  • 🎯 Activity única: Si no necesitas reutilizar código UI
  • 📱 Jetpack Compose: En proyectos modernos, Compose es preferido

🔄 Ciclo de Vida del Fragment

📊 Estados del Fragment

┌──────────────────┐
│   onAttach()     │ ← Fragment se adjunta a Activity
├──────────────────┤
│   onCreate()     │ ← Inicialización básica
├──────────────────┤
│ onCreateView()   │ ⭐ Inflar el layout del Fragment
├──────────────────┤
│onViewCreated()   │ ⭐ Configurar las vistas
├──────────────────┤
│   onStart()      │ ← Fragment visible
├──────────────────┤
│   onResume()     │ ← Fragment interactivo (usuario puede interactuar)
│                  │
│ [ FRAGMENT ACTIVO ]
│                  │
│   onPause()      │ → Pierde el foco
├──────────────────┤
│   onStop()       │ → Ya no es visible
├──────────────────┤
│ onDestroyView()  │ → Se destruye la vista
├──────────────────┤
│   onDestroy()    │ → Se limpia el Fragment
├──────────────────┤
│   onDetach()     │ → Se desvincula de la Activity
└──────────────────┘

⭐ Métodos más importantes

1. onCreateView()

Se usa para inflar el layout XML del Fragment. Aquí defines qué XML se verá.

2. onViewCreated()

Se ejecuta después de crear la vista. Aquí haces findViewById() y configuraciones.

3. onDestroyView()

Se llama cuando la vista se destruye. Útil para limpiar listeners.

💡 Diferencia clave: Fragment vs Activity
Característica Activity Fragment
Independiente ✅ Sí ❌ Depende de Activity
Reutilizable ❌ No ✅ Sí
Ciclo de vida Propio Propio + dependiente de Activity
Context Es un Context requireContext() o activity
Uso principal Pantalla completa Porción de pantalla
⚠️ Importante:

Un Fragment SIEMPRE debe estar dentro de una Activity. No puede existir solo. Si la Activity se destruye, todos sus Fragments también se destruyen.

📱 ListaFloresFragment.kt (Nueva clase)

package com.example.fragments

import android.os.Bundle
import android.view.LayoutInflater
import android.view.View
import android.view.ViewGroup
import android.widget.ArrayAdapter
import android.widget.ListView
import android.widget.Toast
import androidx.fragment.app.Fragment

class ListaFloresFragment : Fragment() {

    // 1️⃣ onCreateView: Inflar el layout
    override fun onCreateView(
        inflater: LayoutInflater,
        container: ViewGroup?,
        savedInstanceState: Bundle?
    ): View? {
        // Inflar el layout del Fragment
        return inflater.inflate(R.layout.fragment_lista, container, false)
    }

    // 2️⃣ onViewCreated: Configurar las vistas
    override fun onViewCreated(view: View, savedInstanceState: Bundle?) {
        super.onViewCreated(view, savedInstanceState)

        // Referenciar el ListView
        val listView = view.findViewById<ListView>(R.id.listView)

        // Datos para el ListView
        val flores = arrayOf(
            "🌸 Gardenia",
            "🌺 Kalanchoe",
            "🌹 Rosa",
            "🌼 Margarita",
            "🌻 Girasol",
            "🏵️ Dalia",
            "🌷 Tulipán"
        )

        // Crear y asignar adapter
        val adapter = ArrayAdapter(
            requireContext(),
            android.R.layout.simple_list_item_1,
            flores
        )
        listView.adapter = adapter

        // Configurar click en items
        listView.setOnItemClickListener { parent, view, position, id ->
            val florSeleccionada = flores[position]
            Toast.makeText(
                requireContext(),
                "Seleccionaste: $florSeleccionada",
                Toast.LENGTH_SHORT
            ).show()
        }
    }
}

📖 Explicación del Código

1️⃣ Herencia de Fragment

  • Debe heredar de androidx.fragment.app.Fragment
  • NO de android.app.Fragment (deprecado)

2️⃣ onCreateView()

  • inflater: Objeto para convertir XML en View
  • container: El ViewGroup padre (la Activity)
  • attachToRoot = false: NO adjuntar automáticamente (lo hace el FragmentManager)

3️⃣ onViewCreated()

  • Se ejecuta DESPUÉS de onCreateView()
  • Aquí haces findViewById() y configuraciones
  • view es la vista inflada en onCreateView()

4️⃣ requireContext()

  • Obtiene el Context de la Activity
  • Lanza excepción si el Fragment no está adjunto (más seguro)
  • Alternativa: context (puede ser null)

💻 Paso 3: Agregar el Fragment a una Activity

📝 Hay 2 formas de agregar un Fragment a una Activity:
  • Estática: En el XML de la Activity
  • Dinámica: Por código (más flexible y recomendada)

Método 1: Estático (XML)

📄 activity_main.xml

<?xml version="1.0" encoding="utf-8"?>
<LinearLayout
    xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical">

    <!-- Agregar Fragment estáticamente -->
    <fragment
        android:id="@+id/fragmentLista"
        android:name="com.example.fragments.ListaFloresFragment"
        android:layout_width="match_parent"
        android:layout_height="match_parent"/>

</LinearLayout>
⚠️ Limitación del método estático:

No puedes reemplazar el Fragment dinámicamente. Está fijo en el XML.

Método 2: Dinámico (Código) ⭐ RECOMENDADO

📄 activity_main.xml

<?xml version="1.0" encoding="utf-8"?>
<LinearLayout
    xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical">

    <!-- Contenedor para el Fragment -->
    <FrameLayout
        android:id="@+id/fragmentContainer"
        android:layout_width="match_parent"
        android:layout_height="match_parent"/>

</LinearLayout>

📱 MainActivity.kt

package com.example.fragments

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)

        // ⭐ Agregar Fragment dinámicamente
        if (savedInstanceState == null) {
            val fragment = ListaFloresFragment()

            supportFragmentManager.beginTransaction()
                .add(R.id.fragmentContainer, fragment)
                .commit()
        }
    }
}
💡 FragmentTransaction - Operaciones importantes:
  • add(containerId, fragment) - Agregar Fragment
  • replace(containerId, fragment) - Reemplazar Fragment
  • remove(fragment) - Eliminar Fragment
  • addToBackStack(null) - Agregar a pila de retroceso
  • commit() - Ejecutar la transacción (obligatorio)
🔍 ¿Por qué if (savedInstanceState == null)?

Evita agregar el Fragment múltiples veces cuando la Activity se recrea (rotación de pantalla). Si savedInstanceState NO es null, significa que la Activity se está recreando y el Fragment ya existe.

🎨 PARTE 3: Master-Detail Pattern (Tablet)

¿Qué es Master-Detail?

Es un patrón de diseño donde se muestra una lista (Master) y los detalles (Detail) de forma simultánea. Ideal para tablets y pantallas grandes.

📱 Diseño Master-Detail

│  ┌─────────────┐  ┌──────────────────┐ │
│  │  Fragment   │  │    Fragment      │ │
│  │   MASTER    │  │    DETAIL        │ │
│  │  (Lista)    │  │   (Detalles)     │ │
│  │             │  │                  │ │
│  │ 🌸 Gardenia │  │  [Imagen Grande] │ │
│  │ 🌺 Kalanchoe│←─│  Nombre          │ │

│     30% width         70% width        │

📱 ListaFloresFragment.kt (Con arrays.xml)

package com.example.fragments

import android.content.Context
import android.os.Bundle
import android.view.LayoutInflater
import android.view.View
import android.view.ViewGroup
import android.widget.ArrayAdapter
import android.widget.ListView
import android.widget.TextView
import androidx.fragment.app.Fragment

class ListaFloresFragment : Fragment() {

    // La Activity implementa este contrato para recibir la flor seleccionada.
    interface OnFlorSeleccionadaListener {
        fun onFlorSeleccionada(flor: Flor)
    }

    private var listener: OnFlorSeleccionadaListener? = null
    private lateinit var flores: List<Flor>

    // Vincula el listener cuando el Fragment se conecta a su Activity.
    override fun onAttach(context: Context) {
        super.onAttach(context)
        if (context is OnFlorSeleccionadaListener) {
            listener = context
        } else {
            throw RuntimeException("$context debe implementar OnFlorSeleccionadaListener")
        }
    }

    // Libera la referencia a la Activity cuando el Fragment se separa.
    override fun onDetach() {
        super.onDetach()
        listener = null
    }

    override fun onCreateView(
        inflater: LayoutInflater,
        container: ViewGroup?,
        savedInstanceState: Bundle?
    ): View? {
        // Infla la interfaz de la lista definida en el recurso XML.
        return inflater.inflate(R.layout.fragment_lista_flores, container, false)
    }

    override fun onViewCreated(view: View, savedInstanceState: Bundle?) {
        super.onViewCreated(view, savedInstanceState)

        // Carga los objetos Flor desde los arrays de recursos.
        flores = cargarFloresDesdeResources()
        val listView = view.findViewById<ListView>(R.id.listViewFlores)

        // Convierte cada flor en una fila usando item_flor.xml.
        val adapter = object : ArrayAdapter<Flor>(
            requireContext(),
            R.layout.item_flor,
            flores
        ) {
            override fun getView(position: Int, convertView: View?, parent: ViewGroup): View {
                // Reutiliza una fila existente o crea una nueva.
                val itemView = convertView ?: LayoutInflater.from(context)
                    .inflate(R.layout.item_flor, parent, false)
                val flor = getItem(position)

                // Muestra los datos visibles de la flor en la fila.
                itemView.findViewById<TextView>(R.id.tvEmoji).text = flor?.emoji
                itemView.findViewById<TextView>(R.id.tvNombre).text = flor?.nombre
                itemView.findViewById<TextView>(R.id.tvCientifico).text = flor?.nombreCientifico

                return itemView
            }
        }

        listView.adapter = adapter

        // Notifica a la Activity cuál flor seleccionó el usuario.
        listView.setOnItemClickListener { _, _, position, _ ->
            val florSeleccionada = flores[position]
            listener?.onFlorSeleccionada(florSeleccionada)
        }
    }

    // Combina los arrays paralelos de arrays.xml en objetos Flor.
    private fun cargarFloresDesdeResources(): List<Flor> {
        val emojis = resources.getStringArray(R.array.flores_emojis)
        val nombres = resources.getStringArray(R.array.flores_nombres)
        val cientificos = resources.getStringArray(R.array.flores_cientificos)
        val familias = resources.getStringArray(R.array.flores_familias)
        val descripciones = resources.getStringArray(R.array.flores_descripciones)

        val listaFlores = mutableListOf<Flor>()
        // Usa el mismo índice para mantener relacionados los datos de cada flor.
        for (i in nombres.indices) {
            listaFlores.add(
                Flor(
                    id = i + 1,
                    nombre = nombres[i],
                    nombreCientifico = cientificos[i],
                    familia = familias[i],
                    descripcion = descripciones[i],
                    emoji = emojis[i]
                )
            )
        }
        return listaFlores
    }
}

📖 Explicación del método cargarFloresDesdeResources()

1️⃣ Carga de Arrays

  • resources.getStringArray(R.array.nombre_array) - Obtiene un array del XML
  • Se cargan los 5 arrays separados (emojis, nombres, científicos, familias, descripciones)

2️⃣ Iteración con índices

  • nombres.indices - Genera rango 0 hasta nombres.size - 1
  • Todos los arrays deben tener la misma cantidad de elementos
  • El índice i accede a la misma posición en todos los arrays

3️⃣ Creación de objetos Flor

  • Combina los datos de los 5 arrays en un solo objeto
  • id = i + 1 - IDs empiezan en 1 (no en 0)
  • Se agrega cada flor a la lista mutable
⚠️ Importante - Sincronización de Arrays:

Todos los arrays en arrays.xml DEBEN tener el mismo número de elementos y en el mismo orden. El índice 0 de todos los arrays representa la misma flor.

Ejemplo:

flores_nombres[0] = "Gardenia"

flores_emojis[0] = "🌼"

📱 DetalleFloresFragment.kt

package com.example.fragments

import android.os.Bundle
import android.view.LayoutInflater
import android.view.View
import android.view.ViewGroup
import android.widget.LinearLayout
import android.widget.TextView
import androidx.fragment.app.Fragment

class DetalleFloresFragment : Fragment() {

    private lateinit var layoutPlaceholder: LinearLayout
    private lateinit var layoutDetalles: LinearLayout
    private lateinit var tvEmojiGrande: TextView
    private lateinit var tvNombreDetalle: TextView
    private lateinit var tvCientificoDetalle: TextView
    private lateinit var tvFamilia: TextView
    private lateinit var tvDescripcion: TextView

    // Conserva la selección para volver a mostrarla al recrear las vistas.
    private var florSeleccionada: Flor? = null

    override fun onCreateView(
        inflater: LayoutInflater,
        container: ViewGroup?,
        savedInstanceState: Bundle?
    ): View? {
        // Infla el layout que contiene el placeholder y los detalles.
        return inflater.inflate(R.layout.fragment_detalle_flor, container, false)
    }

    override fun onViewCreated(view: View, savedInstanceState: Bundle?) {
        super.onViewCreated(view, savedInstanceState)

        // Referenciar vistas
        layoutPlaceholder = view.findViewById(R.id.layoutPlaceholder)
        layoutDetalles = view.findViewById(R.id.layoutDetalles)
        tvEmojiGrande = view.findViewById(R.id.tvEmojiGrande)
        tvNombreDetalle = view.findViewById(R.id.tvNombreDetalle)
        tvCientificoDetalle = view.findViewById(R.id.tvCientificoDetalle)
        tvFamilia = view.findViewById(R.id.tvFamilia)
        tvDescripcion = view.findViewById(R.id.tvDescripcion)

        // Restaura la selección cuando se vuelven a crear las vistas.
        florSeleccionada?.let { actualizarUI(it) }
    }

    // Guarda la flor y actualiza la interfaz si las vistas ya están creadas.
    fun mostrarDetalles(flor: Flor) {
        florSeleccionada = flor
        if (::layoutPlaceholder.isInitialized) {
            actualizarUI(flor)
        }
    }

    // Muestra los datos seleccionados y oculta el placeholder inicial.
    private fun actualizarUI(flor: Flor) {
        layoutPlaceholder.visibility = View.GONE
        layoutDetalles.visibility = View.VISIBLE

        tvEmojiGrande.text = flor.emoji
        tvNombreDetalle.text = flor.nombre
        tvCientificoDetalle.text = flor.nombreCientifico
        tvFamilia.text = "Familia: ${flor.familia}"
        tvDescripcion.text = flor.descripcion
    }
}

📱 MainActivity.kt (Completa)

package com.example.fragments

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity(), 
    ListaFloresFragment.OnFlorSeleccionadaListener {

    private lateinit var detalleFragment: DetalleFloresFragment

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)

        // Agrega los Fragments solo al inicio para evitar duplicarlos al recrear la Activity.
        if (savedInstanceState == null) {
            val listaFragment = ListaFloresFragment()
            detalleFragment = DetalleFloresFragment()

            // Coloca la lista y el detalle en sus contenedores de la pantalla.
            supportFragmentManager.beginTransaction()
                .add(R.id.fragmentListaContainer, listaFragment)
                .add(R.id.fragmentDetalleContainer, detalleFragment)
                .commit()
        } else {
            // Recupera el Fragment de detalle que Android restauró automáticamente.
            detalleFragment = supportFragmentManager
                .findFragmentById(R.id.fragmentDetalleContainer) as DetalleFloresFragment
        }
    }

    // Recibe la flor seleccionada y delega la actualización al Fragment de detalle.
    override fun onFlorSeleccionada(flor: Flor) {
        detalleFragment.mostrarDetalles(flor)
    }
}

📋 Pasos del flujo:

  1. Usuario hace click en una flor de la lista
  2. ListaFloresFragment detecta el click
  3. Llama a listener.onFlorSeleccionada(flor)
  4. La Activity recibe la notificación (implementa la interface)
  5. La Activity llama a detalleFragment.mostrarDetalles(flor)
  6. DetalleFloresFragment actualiza sus vistas con los datos
💡 Puntos Clave del Patrón Master-Detail:
  • Interface: Los Fragments NO se comunican directamente
  • Activity como mediador: Recibe eventos y coordina
  • Layout horizontal: Los dos contenedores están lado a lado
  • Layout weights: 30% para lista, 70% para detalles
  • Separador visual: View de 2dp entre los fragments
⚠️ Para probar en Android Studio:
  • Crear un AVD (Android Virtual Device) tipo Tablet
  • Opciones: Pixel Tablet, Nexus 10, o Medium Tablet
  • O rotar un dispositivo móvil a modo horizontal
