RecyclerView en Android con Kotlin

Todas las prácticas se realizan en la actividad RecyclerViewActivity y su layout activity_recycler_view.xml, dentro del paquete com.example.spinnerlistrecycler.

1. Preparar el proyecto

Trabaja en el proyecto con el paquete com.example.spinnerlistrecycler. Las clases de apoyo se organizan en los subpaquetes model, adapter y layoutmanager:

app/src/main │ ├── java/com/example/spinnerlistrecycler │ ├── RecyclerViewActivity.kt ← actividad de la práctica │ ├── model/ │ │ ├── Usuario.kt ← Parte 4 │ │ └── Fruta.kt ← Parte 5 │ ├── adapter/ │ │ ├── UsuarioViewHolder.kt ← Parte 4 │ │ ├── UsuarioAdapter.kt ← Parte 4 │ │ ├── FrutaAdapter.kt ← Parte 5 │ │ └── OnFrutaClickListener.kt ← Parte 7 │ └── layoutmanager/ │ └── UsuarioLayoutManager.kt ← Parte 4 │ ├── res/layout │ ├── activity_recycler_view.xml ← contenedor del RecyclerView │ ├── item_usuario.xml ← fila de usuario │ └── item_fruta.xml ← fila de fruta │ ├── res/values │ └── data_frutas.xml ← datos de frutas │ └── AndroidManifest.xml
Crear un subpaquete: clic derecho en com.example.spinnerlistrecycler → New → Package → escribe model (o adapter, layoutmanager). Luego, clic derecho en el subpaquete → New → Kotlin Class/File.

1.1 Agregar las dependencias

Abre build.gradle.kts (Module :app) y agrega estas líneas dentro de dependencies. Después pulsa Sync Now.

dependencies {
    // RecyclerView y CardView
    implementation("androidx.recyclerview:recyclerview:1.3.2")
    implementation("androidx.cardview:cardview:1.0.0")

    // ... otras dependencias ...
}
Si tu proyecto usa Groovy (build.gradle sin .kts), escribe implementation 'androidx.recyclerview:recyclerview:1.3.2' y implementation 'androidx.cardview:cardview:1.0.0'.

1.2 Crear RecyclerViewActivity

  1. En el panel Project, haz clic derecho en el paquete com.example.spinnerlistrecycler.
  2. Selecciona New → Activity → Empty Views Activity.
  3. En Activity Name escribe RecyclerViewActivity. El campo Layout Name se completa como activity_recycler_view.
  4. Verifica que Language sea Kotlin y pulsa Finish.

1.3 Abrir RecyclerViewActivity al iniciar la app

En AndroidManifest.xml, el intent-filter con MAIN y LAUNCHER indica qué actividad arranca primero. Colócalo en RecyclerViewActivity y quítalo de las demás actividades (por ejemplo SpinnerActivity o ListViewActivity), que quedan con android:exported="false".

2. ¿Qué es RecyclerView?

RecyclerView muestra grandes conjuntos de datos de forma eficiente. Es la evolución moderna de ListView y optimiza el rendimiento mediante el reciclaje de vistas.

2.1 Concepto de reciclaje

ListView tradicional

Puede crear una vista nueva para cada ítem: 1000 ítems pueden llegar a generar muchas vistas y llamadas a findViewById().

RecyclerView

Crea solo las vistas visibles (~10–15). Al hacer scroll, reutiliza esas vistas con datos nuevos. 1000 ítems ≈ 15 vistas.

1000 datos → ~15 ViewHolders → se reciclan al hacer scroll ♻️

Ventajas

  • Alto rendimiento: recicla vistas.
  • Menor consumo de memoria.
  • Varios diseños: lineal, cuadrícula, escalonado.
  • Animaciones integradas al agregar, eliminar o mover.
  • Personalizable con ItemDecoration e ItemAnimator.
  • ViewHolder obligatorio: código más ordenado.

Consideraciones

  • Requiere más código inicial.
  • Necesita configurar un LayoutManager.
  • Curva de aprendizaje: Adapter y ViewHolder.
Situación ListView RecyclerView
Lista pequeña (< 50 ítems) Funciona Mejor
Lista grande (> 100 ítems) Lento Excelente
Cuadrícula u horizontal Complicado Fácil
Animaciones Manuales Integradas
Proyecto nuevo Legacy Recomendado
Recomendación de Google: usar RecyclerView en lugar de ListView en proyectos nuevos. ListView se considera legacy.

3. Arquitectura de RecyclerView

1. RecyclerView

Contenedor que muestra los ítems en pantalla.

2. Adapter

Crea los ViewHolders, les asigna los datos e indica cuántos ítems hay.

3. ViewHolder

Guarda las referencias a las vistas de cada ítem. Evita llamadas repetidas a findViewById().

4. LayoutManager

LinearLayoutManager, GridLayoutManager o StaggeredGridLayoutManager.

5. ItemDecoration

Opcional. Separadores, márgenes y decoraciones.

6. ItemAnimator

Opcional. Animaciones al agregar, eliminar o mover ítems.

Datos (List) → Adapter → ViewHolder → RecyclerView → Pantalla

3.1 Métodos obligatorios del Adapter

Método Cuándo se llama Qué hace
onCreateViewHolder() Solo cuando se necesita una vista nueva (unas 12–15 veces). Infla el layout del ítem y crea el ViewHolder.
onBindViewHolder() Cada vez que un ítem va a mostrarse (muchas veces al hacer scroll). Asigna los datos de la posición indicada a las vistas.
getItemCount() Cuando el RecyclerView necesita saber el total. Devuelve la cantidad de ítems.
Patrón ViewHolder: es obligatorio en RecyclerView. findViewById() solo se ejecuta al crear el ViewHolder; al reciclarlo, se reutilizan las referencias guardadas. Mil desplazamientos equivalen a unas diez llamadas iniciales, no a mil.

4.4 ViewHolder

Guarda las referencias a las vistas del XML. Se hace una sola vez por ítem creado.

package com.example.spinnerlistrecycler.adapter

import android.view.View
import android.widget.TextView
import androidx.recyclerview.widget.RecyclerView
import com.example.spinnerlistrecycler.R

// COMPONENTE 3: VIEWHOLDER
// Guarda las referencias a las vistas de cada ítem
class UsuarioViewHolder(view: View) : RecyclerView.ViewHolder(view) {

    // Referencias a los TextView de item_usuario.xml
    val tvNombre: TextView = view.findViewById(R.id.tvNombre)
    val tvCorreo: TextView = view.findViewById(R.id.tvCorreo)
}
Import de R: como el archivo está en un subpaquete, debe importar com.example.spinnerlistrecycler.R para acceder a los ids y layouts.

4.5 Adapter

Es el puente entre los datos y la vista. Implementa onCreateViewHolder, onBindViewHolder y getItemCount.

package com.example.spinnerlistrecycler.adapter

import android.view.LayoutInflater
import android.view.ViewGroup
import android.widget.Toast
import androidx.recyclerview.widget.RecyclerView
import com.example.spinnerlistrecycler.R
import com.example.spinnerlistrecycler.model.Usuario

// COMPONENTE 2: ADAPTER
// Conecta la lista de usuarios con el RecyclerView
class UsuarioAdapter(private val listaUsuarios: List<Usuario>) :
    RecyclerView.Adapter<UsuarioViewHolder>() {

    // 1. CREA un ViewHolder: "infla" (convierte XML en vista) item_usuario.xml
    override fun onCreateViewHolder(parent: ViewGroup, viewType: Int): UsuarioViewHolder {
        val view = LayoutInflater.from(parent.context)
            .inflate(R.layout.item_usuario, parent, false)
        return UsuarioViewHolder(view)
    }

    // 2. LLENA el ViewHolder con los datos de la posición
    override fun onBindViewHolder(holder: UsuarioViewHolder, position: Int) {
        val usuario = listaUsuarios[position]

        holder.tvNombre.text = usuario.nombre
        holder.tvCorreo.text = usuario.correo

        // Detectar clic en cada ítem
        holder.itemView.setOnClickListener {
            Toast.makeText(
                holder.itemView.context,
                "Tocaste a: ${usuario.nombre}",
                Toast.LENGTH_SHORT
            ).show()
        }
    }

    // 3. Devuelve la CANTIDAD total de ítems
    override fun getItemCount(): Int = listaUsuarios.size
}

4.6 LayoutManager personalizado

Decide cómo se organizan los ítems. Hereda de LinearLayoutManager para fijar la orientación y permitir personalizaciones futuras.

package com.example.spinnerlistrecycler.layoutmanager

import android.content.Context
import androidx.recyclerview.widget.LinearLayoutManager

// COMPONENTE 4: LAYOUTMANAGER
// Decide CÓMO se acomodan los elementos en pantalla.
// Otras opciones:
// - GridLayoutManager → cuadrícula (ej.: 2 columnas)
// - StaggeredGridLayoutManager → estilo Pinterest
class UsuarioLayoutManager(context: Context) : LinearLayoutManager(context) {

    init {
        // Orientación: VERTICAL (por defecto) u HORIZONTAL
        orientation = VERTICAL

        // true invierte el orden (último ítem arriba)
        reverseLayout = false
    }
}

4.7 Actividad

Aquí se une todo: se conecta el RecyclerView, se preparan los datos, se asigna el LayoutManager y finalmente el Adapter.

package com.example.spinnerlistrecycler

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity
import androidx.recyclerview.widget.RecyclerView
import com.example.spinnerlistrecycler.adapter.UsuarioAdapter
import com.example.spinnerlistrecycler.layoutmanager.UsuarioLayoutManager
import com.example.spinnerlistrecycler.model.Usuario

class RecyclerViewActivity : AppCompatActivity() {

    private lateinit var recyclerView: RecyclerView

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_recycler_view)

        // 1. Conectar con el RecyclerView del XML
        recyclerView = findViewById(R.id.recyclerViewUsuarios)

        // 2. Preparar la lista de datos
        val listaUsuarios = listOf(
            Usuario("Ana García", "ana@correo.com"),
            Usuario("Luis Pérez", "luis@correo.com"),
            Usuario("María Torres", "maria@correo.com"),
            Usuario("Carlos Ruiz", "carlos@correo.com"),
            Usuario("Sofía Mendoza", "sofia@correo.com"),
            Usuario("Pedro Sánchez", "pedro@correo.com"),
            Usuario("Lucía Flores", "lucia@correo.com"),
            Usuario("Diego Castro", "diego@correo.com")
        )

        // 3. CRÍTICO: asignar el LayoutManager (sin él la lista no se muestra)
        recyclerView.layoutManager = UsuarioLayoutManager(this)

        // 4. Asignar el Adapter con la lista de datos
        recyclerView.adapter = UsuarioAdapter(listaUsuarios)
    }
}
Punto crítico: sin un LayoutManager, el RecyclerView no sabe cómo acomodar los ítems y la lista queda vacía. UsuarioLayoutManager(this) equivale a LinearLayoutManager(this) vertical.

5.4 Adapter con ViewHolder interno

A diferencia del proyecto 1, aquí el ViewHolder se declara dentro del Adapter.

package com.example.spinnerlistrecycler.adapter

import android.view.LayoutInflater
import android.view.View
import android.view.ViewGroup
import android.widget.TextView
import androidx.recyclerview.widget.RecyclerView
import com.example.spinnerlistrecycler.R
import com.example.spinnerlistrecycler.model.Fruta

class FrutaAdapter(
    private val frutas: List<Fruta>
) : RecyclerView.Adapter<FrutaAdapter.FrutaViewHolder>() {

    // ViewHolder: guarda las referencias a las vistas
    class FrutaViewHolder(itemView: View) : RecyclerView.ViewHolder(itemView) {
        val tvEmoji: TextView = itemView.findViewById(R.id.tvEmoji)
        val tvNombre: TextView = itemView.findViewById(R.id.tvNombre)
    }

    // 1. Crear el ViewHolder (inflar el layout)
    override fun onCreateViewHolder(parent: ViewGroup, viewType: Int): FrutaViewHolder {
        val view = LayoutInflater.from(parent.context)
            .inflate(R.layout.item_fruta, parent, false)
        return FrutaViewHolder(view)
    }

    // 2. Vincular los datos con el ViewHolder
    override fun onBindViewHolder(holder: FrutaViewHolder, position: Int) {
        val fruta = frutas[position]
        holder.tvEmoji.text = fruta.emoji
        holder.tvNombre.text = fruta.nombre
    }

    // 3. Cantidad de ítems
    override fun getItemCount(): Int = frutas.size
}
Parte Explicación Analogía
Declaración de la clase Recibe la lista de frutas, hereda de RecyclerView.Adapter y usa FrutaViewHolder. —
FrutaViewHolder Guarda las referencias a los TextView. Post-its en las páginas importantes de un libro.
onCreateViewHolder() Infla item_fruta.xml. Pocas veces. Construir el molde de la galleta.
onBindViewHolder() Asigna la fruta de la posición. Muchas veces. Rellenar el molde con masa.
getItemCount() Total de ítems; indica dónde termina el scroll. —

package com.example.spinnerlistrecycler

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity
import androidx.recyclerview.widget.LinearLayoutManager
import androidx.recyclerview.widget.RecyclerView
import com.example.spinnerlistrecycler.adapter.FrutaAdapter
import com.example.spinnerlistrecycler.model.Fruta

class RecyclerViewActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_recycler_view)

        // 1. Referenciar el RecyclerView
        val recyclerView = findViewById<RecyclerView>(R.id.recyclerView)

        // 2. Cargar los datos desde res/values/data_frutas.xml
        val nombres = resources.getStringArray(R.array.frutas_nombres)
        val emojis = resources.getStringArray(R.array.frutas_emojis)

        // Construir la lista final: Fruta(emoji, nombre)
        val frutas = nombres.zip(emojis) { nombre, emoji ->
            Fruta(emoji, nombre)
        }

        // 3. Crear y asignar el adapter
        recyclerView.adapter = FrutaAdapter(frutas)

        // 4. Configurar el LayoutManager (OBLIGATORIO)
        recyclerView.layoutManager = LinearLayoutManager(this)
    }
}
zip: recorre los dos arreglos a la vez y combina el elemento i de cada uno. Así "Manzana" y "🍎" forman Fruta("🍎", "Manzana").

5.7 Proceso completo

  1. getItemCount() → «Tengo 20 frutas».
  2. onCreateViewHolder() → «Creo ~12 vistas» (solo al inicio).
  3. onBindViewHolder(0) → «Relleno la vista 1 con 🍎 Manzana».
  4. onBindViewHolder(1) → «Relleno la vista 2 con 🍌 Plátano».
  5. El usuario hace scroll.
  6. onBindViewHolder(12) → «Reciclo la vista 1 con otros datos».
Pasos para crear un RecyclerView:
  1. Agregar la dependencia en build.gradle.kts.
  2. Crear el layout del ítem (item_fruta.xml).
  3. Crear la data class (Fruta.kt).
  4. Crear el Adapter con su ViewHolder.
  5. Preparar los datos (data_frutas.xml).
  6. Agregar el RecyclerView al layout de la actividad.
  7. Configurar LayoutManager y Adapter en la actividad.

8. CRUD dinámico: agregar, editar y eliminar

Para modificar la lista, el Adapter debe trabajar con un ArrayList (mutable) y notificar cada cambio con el método adecuado.

Método Uso Animación
notifyItemInserted(pos) Ítem agregado Sí
notifyItemRemoved(pos) Ítem eliminado Sí
notifyItemChanged(pos) Ítem modificado Sí
notifyItemMoved(from, to) Ítem movido Sí
notifyDataSetChanged() Redibujar todo No
Buena práctica: usa notifyItemInserted(), notifyItemRemoved() y similares en lugar de notifyDataSetChanged(): obtienes animaciones automáticas y mejor rendimiento.

8.1 Adapter con ArrayList

package com.example.spinnerlistrecycler.adapter

import android.view.LayoutInflater
import android.view.View
import android.view.ViewGroup
import android.widget.TextView
import androidx.appcompat.app.AlertDialog
import androidx.recyclerview.widget.RecyclerView
import com.example.spinnerlistrecycler.R
import com.example.spinnerlistrecycler.model.Fruta

class FrutaAdapter(
    private val frutas: ArrayList<Fruta>,             // ArrayList mutable
    private val onEditar: (Int, Fruta) -> Unit        // Clic: editar
) : RecyclerView.Adapter<FrutaAdapter.FrutaViewHolder>() {

    class FrutaViewHolder(itemView: View) : RecyclerView.ViewHolder(itemView) {
        val tvEmoji: TextView = itemView.findViewById(R.id.tvEmoji)
        val tvNombre: TextView = itemView.findViewById(R.id.tvNombre)
    }

    override fun onCreateViewHolder(parent: ViewGroup, viewType: Int): FrutaViewHolder {
        val view = LayoutInflater.from(parent.context)
            .inflate(R.layout.item_fruta, parent, false)
        return FrutaViewHolder(view)
    }

    override fun onBindViewHolder(holder: FrutaViewHolder, position: Int) {
        val fruta = frutas[position]
        holder.tvEmoji.text = fruta.emoji
        holder.tvNombre.text = fruta.nombre

        // Clic: editar
        holder.itemView.setOnClickListener {
            val pos = holder.bindingAdapterPosition
            if (pos != RecyclerView.NO_POSITION) onEditar(pos, frutas[pos])
        }

        // Clic largo: eliminar con confirmación
        holder.itemView.setOnLongClickListener {
            AlertDialog.Builder(holder.itemView.context)
                .setTitle("Eliminar")
                .setMessage("¿Eliminar ${fruta.nombre}?")
                .setPositiveButton("Eliminar") { _, _ ->
                    val pos = holder.bindingAdapterPosition
                    if (pos != RecyclerView.NO_POSITION) eliminarFruta(pos)
                }
                .setNegativeButton("Cancelar", null)
                .show()
            true
        }
    }

    override fun getItemCount(): Int = frutas.size

    // CREATE: agregar al final
    fun agregarFruta(fruta: Fruta) {
        frutas.add(fruta)
        notifyItemInserted(frutas.size - 1)
    }

    // UPDATE: reemplazar en la posición
    fun actualizarFruta(position: Int, nuevaFruta: Fruta) {
        frutas[position] = nuevaFruta
        notifyItemChanged(position)
    }

    // DELETE: quitar de la posición
    fun eliminarFruta(position: Int) {
        frutas.removeAt(position)
        notifyItemRemoved(position)
    }
}
bindingAdapterPosition: después de eliminar o insertar, la variable position de onBindViewHolder puede quedar desactualizada. holder.bindingAdapterPosition devuelve la posición actual del ítem en el momento del clic.

class RecyclerViewActivity : AppCompatActivity() {

    private lateinit var adapter: FrutaAdapter
    private val frutas = ArrayList<Fruta>()

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_recycler_view)

        val recyclerView = findViewById<RecyclerView>(R.id.recyclerView)
        val btnAgregar = findViewById<Button>(R.id.btnAgregar)

        // Datos iniciales desde res/values/data_frutas.xml
        val nombres = resources.getStringArray(R.array.frutas_nombres)

        // Clic en un ítem: abrir el diálogo de edición
        adapter = FrutaAdapter(frutas) { position, fruta ->
            mostrarDialogoEditar(position, fruta)
        }
        recyclerView.adapter = adapter
        recyclerView.layoutManager = LinearLayoutManager(this)

        // Botón para agregar
        btnAgregar.setOnClickListener {
            mostrarDialogoAgregar()
        }
    }

    private fun mostrarDialogoAgregar() {
        val input = EditText(this)
        input.hint = "Nombre de la fruta"

        AlertDialog.Builder(this)
            .setTitle("Agregar fruta")
            .setView(input)
            .setPositiveButton("Agregar") { _, _ ->
                val nombre = input.text.toString().trim()
                if (nombre.isNotEmpty()) {
                    adapter.agregarFruta(Fruta("🍓", nombre))
                    Toast.makeText(this, "Fruta agregada", Toast.LENGTH_SHORT).show()
                }
            }
            .setNegativeButton("Cancelar", null)
            .show()
    }

    private fun mostrarDialogoEditar(position: Int, fruta: Fruta) {
        val input = EditText(this)
        input.setText(fruta.nombre)

        AlertDialog.Builder(this)
            .setTitle("Editar fruta")
            .setView(input)
            .setPositiveButton("Guardar") { _, _ ->
                val nombre = input.text.toString().trim()
                if (nombre.isNotEmpty()) {
                    adapter.actualizarFruta(position, fruta.copy(nombre = nombre))
                }
            }
            .setNegativeButton("Cancelar", null)
            .show()
    }
}

9.5 Búsqueda y filtrado

El Adapter guarda la lista completa y una lista filtrada. Todos los métodos trabajan con la lista filtrada:

package com.example.spinnerlistrecycler.adapter

import android.view.LayoutInflater
import android.view.View
import android.view.ViewGroup
import android.widget.TextView
import androidx.recyclerview.widget.RecyclerView
import com.example.spinnerlistrecycler.R
import com.example.spinnerlistrecycler.model.Fruta

class FrutaAdapter(
    private val frutas: List<Fruta>
) : RecyclerView.Adapter<FrutaAdapter.FrutaViewHolder>() {

    // Copia que se muestra en pantalla
    private val frutasFiltradas = ArrayList<Fruta>(frutas)

    class FrutaViewHolder(itemView: View) : RecyclerView.ViewHolder(itemView) {
        val tvEmoji: TextView = itemView.findViewById(R.id.tvEmoji)
        val tvNombre: TextView = itemView.findViewById(R.id.tvNombre)
    }

    override fun onCreateViewHolder(parent: ViewGroup, viewType: Int): FrutaViewHolder {
        val view = LayoutInflater.from(parent.context)
            .inflate(R.layout.item_fruta, parent, false)
        return FrutaViewHolder(view)
    }

    override fun onBindViewHolder(holder: FrutaViewHolder, position: Int) {
        val fruta = frutasFiltradas[position]
        holder.tvEmoji.text = fruta.emoji
        holder.tvNombre.text = fruta.nombre
    }

    override fun getItemCount(): Int = frutasFiltradas.size

    fun filtrar(texto: String) {
        frutasFiltradas.clear()

        if (texto.isEmpty()) {
            frutasFiltradas.addAll(frutas)
        } else {
            val busqueda = texto.lowercase()
            for (fruta in frutas) {
                if (fruta.nombre.lowercase().contains(busqueda)) {
                    frutasFiltradas.add(fruta)
                }
            }
        }

        notifyDataSetChanged()
    }
}
