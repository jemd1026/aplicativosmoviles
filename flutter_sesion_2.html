1 TextField y controles de formulario

60 minutos · captura de datos y estado del formulario

Una app deja de ser solo una maqueta cuando puede recibir datos. En Flutter, eso empieza con controles de formulario. El TextField captura texto; Switch, Checkbox, RadioListTile y DropdownButtonFormField permiten decisiones y opciones.

TextField se usa para escribir texto como nombre, titulo o descripcion.

Switch representa una decision binaria: activo o inactivo.

Checkbox marca o desmarca una opcion concreta.

RadioListTile permite elegir solo una opcion entre varias.

DropdownButtonFormField funciona como un select: muestra varias opciones y deja elegir una.

Estructura completa. La clase _FormularioDemoState no se usa sola. Siempre debe ir unida a un StatefulWidget que la invoque con createState(). Este es el ejemplo completo y funcional:

lib/main.dart - formulario basico completo 
import 'package:flutter/material.dart';

            void main() {
            runApp(MiApp()); // inicia la aplicacion
            }

            class MiApp extends StatelessWidget {
            @override
            Widget build(BuildContext context) {
            return MaterialApp(
            debugShowCheckedModeBanner: false,
            theme: ThemeData(useMaterial3: true),
            home: FormularioDemo(), // primera pantalla
            );
            }
            }

            class FormularioDemo extends StatefulWidget {
            @override
            State<FormularioDemo> createState() => _FormularioDemoState(); // conecta el widget con su estado
            }

            class _FormularioDemoState extends State<FormularioDemo> {
            final nombreController = TextEditingController(); // controla el texto escrito
            bool recibirNotificaciones = true; // estado del switch
            bool aceptaTerminos = false; // estado del checkbox
            String prioridad = 'Media'; // valor del radio
            String? categoria = 'Estudio'; // valor del select

            @override
            Widget build(BuildContext context) {
            return Scaffold(
            appBar: AppBar(title: Text('Formulario simple')),
            body: Padding(
            padding: EdgeInsets.all(16),
            child: ListView(
            children: [
            TextField(
            controller: nombreController,
            decoration: InputDecoration(
            labelText: 'Nombre',
            border: OutlineInputBorder(),
            ),
            ),
            SizedBox(height: 16),
            SwitchListTile(
            title: Text('Recibir notificaciones'),
            value: recibirNotificaciones,
            onChanged: (valor) => setState(() => recibirNotificaciones = valor),
            ),
            CheckboxListTile(
            title: Text('Acepto terminos'),
            value: aceptaTerminos,
            onChanged: (valor) => setState(() => aceptaTerminos = valor ?? false),
            ),
            RadioListTile<String>(
            title: Text('Prioridad alta'),
            value: 'Alta',
            groupValue: prioridad,
            onChanged: (valor) => setState(() => prioridad = valor!),
            ),
            RadioListTile<String>(
            title: Text('Prioridad media'),
            value: 'Media',
            groupValue: prioridad,
            onChanged: (valor) => setState(() => prioridad = valor!),
            ),
            DropdownButtonFormField<String>(
            value: categoria,
            items: ['Estudio', 'Trabajo', 'Personal']
              .map((item) => DropdownMenuItem(value: item, child: Text(item)))
              .toList(),
            onChanged: (valor) => setState(() => categoria = valor),
            decoration: InputDecoration(labelText: 'Categoria'),
            ),
            ],
            ),
            ),
            );
            }

            @override
            void dispose() {
            nombreController.dispose(); // libera el controlador al cerrar la pantalla
            super.dispose();
            }
            }
💡

Lectura correcta de la estructura: MiApp arranca la aplicacion, FormularioDemo representa la pantalla, y _FormularioDemoState guarda los valores que cambian mientras se usa el formulario.

💡

Regla simple: si el control cambia en pantalla, su valor debe vivir en una variable de estado y actualizarse con setState().

2 ListView con datos en memoria y JSON local

60 minutos · listas dinamicas sin base de datos

Mostrar una lista en Flutter no requiere base de datos. Primero se trabaja con datos en memoria; después, si hace falta, esos mismos datos pueden venir de un JSON local o de una API.

Forma Ejemplo Cuándo usarla
Lista en memoria List<String> Cuando solo quieren practicar interfaz y estado.
Lista de objetos List<Producto> Cuando cada item tiene varios datos relacionados.
JSON local List<Map<String, dynamic>> Cuando quieren simular data sin internet ni API.

Ejemplo completo 1. Aquí tienen la estructura completa para trabajar con JSON simulado, convertirlo a objetos con fromJson y dejar la lista lista para mostrarse en pantalla.

lib/main.dart - JSON simulado + clase desde fromJson 
import 'package:flutter/material.dart'; // widgets base de Flutter

            void main() { // punto de entrada
            runApp(MiApp()); // inicia la aplicación
            }

            class MiApp extends StatelessWidget {
            @override
            Widget build(BuildContext context) {
            return MaterialApp(
            debugShowCheckedModeBanner: false,
            theme: ThemeData(useMaterial3: true),
            home: ProductosPage(),
            );
            }
            }

            // JSON local simulado: aquí la data todavía no viene de internet
            final productosJson = [
            {'nombre': 'Arroz', 'precio': 4.50, 'stock': 8},
            {'nombre': 'Leche', 'precio': 3.20, 'stock': 4},
            {'nombre': 'Pan', 'precio': 0.80, 'stock': 20},
            {'nombre': 'Huevos', 'precio': 7.00, 'stock': 12},
            ];

            class Producto { // modelo que representa cada producto
            String nombre;
            double precio;
            int stock;

            Producto({
            required this.nombre,
            required this.precio,
            required this.stock,
            });

            factory Producto.fromJson(Map<String, dynamic> json) { // convierte un Map en objeto
            return Producto(
            nombre: json['nombre'],
            precio: (json['precio'] as num).toDouble(), // asegura tipo double
            stock: json['stock'],
            );
            }
            }

            class ProductosPage extends StatelessWidget { // pantalla que usa la data ya convertida
            @override
            Widget build(BuildContext context) {
            final productos = productosJson
            .map((item) => Producto.fromJson(item))
            .toList(); // convierte cada map en un objeto Producto

            return Scaffold(
            appBar: AppBar(title: Text('Productos desde JSON local')),
            body: Center(
            child: Text('Total de productos: ${productos.length}'),
            ),
            );
            }
            }

Ejemplo completo 2. Ahora el mismo escenario, pero mostrando los objetos con ListView.builder dentro de una pantalla funcional.

lib/main.dart - ListView.builder con objetos 
import 'package:flutter/material.dart'; // widgets visuales de Flutter

            void main() { // arranque de la app
            runApp(MiApp()); // dibuja el widget principal
            }

            class MiApp extends StatelessWidget {
            @override
            Widget build(BuildContext context) {
            return MaterialApp(
            debugShowCheckedModeBanner: false,
            theme: ThemeData(useMaterial3: true),
            home: ProductosListPage(),
            );
            }
            }

            final productosJson = [ // lista que simula una respuesta JSON
            {'nombre': 'Arroz', 'precio': 4.50, 'stock': 8},
            {'nombre': 'Leche', 'precio': 3.20, 'stock': 4},
            {'nombre': 'Pan', 'precio': 0.80, 'stock': 20},
            {'nombre': 'Huevos', 'precio': 7.00, 'stock': 12},
            ];

            class Producto {
            String nombre;
            double precio;
            int stock;

            Producto({
            required this.nombre,
            required this.precio,
            required this.stock,
            });

            factory Producto.fromJson(Map<String, dynamic> json) {
            return Producto(
            nombre: json['nombre'],
            precio: (json['precio'] as num).toDouble(),
            stock: json['stock'],
            );
            }
            }

            class ProductosListPage extends StatelessWidget { // pantalla que mostrará la lista
            @override
            Widget build(BuildContext context) {
            final productos = productosJson
            .map((item) => Producto.fromJson(item))
            .toList(); // transforma todos los Map en objetos

            return Scaffold(
            appBar: AppBar(title: Text('Lista de productos')),
            body: ListView.builder( // construye solo los items visibles
            itemCount: productos.length, // cantidad total de elementos
            itemBuilder: (context, index) {
            final producto = productos[index]; // obtiene el item actual
            return Card(
            margin: EdgeInsets.symmetric(horizontal: 12, vertical: 6),
            child: ListTile(
            leading: CircleAvatar(child: Text('${index + 1}')),
            title: Text(producto.nombre),
            subtitle: Text('Stock: ${producto.stock}'),
            trailing: Text('S/ ${producto.precio.toStringAsFixed(2)}'),
            ),
            );
            },
            ),
            );
            }
            }
⚠

Diferencia con Android nativo: en Android moderno se usa mucho RecyclerView. En Flutter, el equivalente practico para empezar suele ser ListView.builder.

3 Navegacion entre pantallas y separar widgets

55 minutos · organizar mejor la app

Cuando una app empieza a crecer, dejar todo en main.dart deja de ser practico. Esta sesion ya debe acostumbrarlos a separar pantallas, widgets y modelos en archivos distintos.

Navegacion entre pantallas se hace con Navigator.push() para entrar y Navigator.pop() para volver.

Separar widgets en archivos mejora lectura, mantenimiento y reutilizacion.

Regla basica: main.dart inicia la app; las pantallas viven en otros archivos; los widgets reutilizables van a una carpeta propia; los modelos se definen aparte.

Estructura sugerida dentro de lib/

            models/
              producto.dart
            pages/

4 Tema, Material 3 y persistencia basica

45 minutos · dar identidad y guardar datos simples

Una app tambien debe verse consistente. Flutter permite configurar el estilo general desde MaterialApp usando ThemeData. A eso se suma la persistencia basica cuando quieren que un dato no desaparezca al cerrar la app.

⚠

Antes de ejecutar este ejemplo: como aqui se usa shared_preferences, primero deben agregar la dependencia en pubspec.yaml y luego ejecutar flutter pub get. Si no hacen ese paso, Flutter mostrara errores de paquete no encontrado.

Ejemplo de dependencia en pubspec.yaml:

pubspec.yaml 
dependencies:
            flutter:
              sdk: flutter
            shared_preferences: ^2.2.3

Luego, en terminal:

terminal 
flutter pub get

Regla practica: si un ejemplo importa un paquete que no viene por defecto con Flutter, primero se instala en pubspec.yaml, despues se ejecuta flutter pub get, y recien luego se corre la app.

Ejemplo completo y funcional. Este ejemplo combina Material 3 con una persistencia muy simple usando SharedPreferences. La pantalla permite cambiar entre dos colores base y guardar una lista corta de nombres para recuperarla al volver a abrir la app.

lib/main.dart - tema Material 3 + persistencia basica 
import 'package:flutter/material.dart'; // widgets visuales
            import 'package:shared_preferences/shared_preferences.dart'; // persistencia simple en el dispositivo

            void main() { // punto de entrada
            runApp(MiApp());
            }

            class MiApp extends StatefulWidget { // debe ser con estado porque el tema puede cambiar
            @override
            State<MiApp> createState() => _MiAppState();
            }

            class _MiAppState extends State<MiApp> {
            Color colorBase = Colors.teal; // color inicial del tema

            @override
            Widget build(BuildContext context) {
            return MaterialApp(
            debugShowCheckedModeBanner: false,
            theme: ThemeData(
            useMaterial3: true, // activa Material 3
            colorScheme: ColorScheme.fromSeed(seedColor: colorBase), // genera la paleta general
            inputDecorationTheme: const InputDecorationTheme(
            border: OutlineInputBorder(),
            ),
            ),
            home: TemaPersistenciaPage(
            onCambiarColor: (nuevoColor) {
            setState(() {
            colorBase = nuevoColor; // cambia el tema de toda la app
            });
            },
            ),
            );
            }
            }

            class TemaPersistenciaPage extends StatefulWidget {
            final Function(Color) onCambiarColor;

            const TemaPersistenciaPage({
            super.key,
            required this.onCambiarColor,
            });

            @override
            State<TemaPersistenciaPage> createState() => _TemaPersistenciaPageState();
            }

            class _TemaPersistenciaPageState extends State<TemaPersistenciaPage> {
            final nombreController = TextEditingController(); // maneja el texto del input
            List<String> nombres = []; // lista simple para guardar

            @override
            void initState() {
            super.initState();
            cargarDatos(); // recupera lo guardado al iniciar
            }

            Future<void> cargarDatos() async {
            final prefs = await SharedPreferences.getInstance(); // abre acceso al almacenamiento local
            final datosGuardados = prefs.getStringList('nombres_guardados') ?? [];

            setState(() {
            nombres = datosGuardados; // actualiza la lista visible en pantalla
            });
            }

            Future<void> guardarDatos() async {
            final prefs = await SharedPreferences.getInstance();
            await prefs.setStringList('nombres_guardados', nombres); // persiste la lista
            }

            void agregarNombre() {
            if (nombreController.text.isNotEmpty) {
            setState(() {
            nombres.add(nombreController.text); // agrega el nuevo nombre a memoria
            });
            nombreController.clear(); // limpia el campo luego de guardar
            guardarDatos(); // persiste el cambio en disco
            }
            }

            @override
            Widget build(BuildContext context) {
            return Scaffold(
            appBar: AppBar(
            title: const Text('Tema y persistencia basica'),
            ),
            body: Padding(
            padding: const EdgeInsets.all(16),
            child: Column(
            children: [
            Row(
            children: [
            Expanded(
            child: TextField(
            controller: nombreController,
            decoration: const InputDecoration(
            labelText: 'Nombre',
            ),
            ),
            ),
            SizedBox(width: 10),
            FilledButton(
            onPressed: agregarNombre,
            child: const Text('Guardar'),
            ),
            ],
            ),
            SizedBox(height: 16),
            Wrap(
            spacing: 10,
            children: [
            FilledButton(
            onPressed: () => widget.onCambiarColor(Colors.teal), // cambia el color base del tema
            child: const Text('Tema teal'),
            ),
            FilledButton(
            onPressed: () => widget.onCambiarColor(Colors.deepPurple), // aplica otro color global
            child: const Text('Tema morado'),
            ),
            ],
            ),
            SizedBox(height: 20),
            Expanded(
            child: ListView.builder( // muestra todos los nombres guardados
            itemCount: nombres.length,
            itemBuilder: (context, index) {
            return Card(
            child: ListTile(
            title: Text(nombres[index]),
            ),
            );
            },
            ),
            ),
            ],
            ),
            ),
            );
            }

            @override
            void dispose() {
            nombreController.dispose();
            super.dispose();
            }
            }
⚠

Persistencia basica no es lo mismo que una base de datos completa. SharedPreferences sirve para configuraciones y datos simples. Si despues necesitan estructuras mas complejas, ahi si conviene SQLite, Hive o una API.
