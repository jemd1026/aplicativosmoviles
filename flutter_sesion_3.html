Las 4 acciones de una API REST

Cada petición tiene un método (qué quiero hacer) y una ruta (sobre qué cosa). Con solo 4 métodos se hace todo el inventario. A eso le llaman CRUD: Create, Read, Update, Delete.

MétodoPara qué sirveEjemplo en MiBodegaEn el restaurante
GETLeer datosGET /productos"¿Qué platos hay?"
POSTCrear algo nuevoPOST /productos"Quiero pedir este plato"
PUTModificar algo que ya existePUT /productos/5"Cambie mi pedido N° 5"
DELETEEliminarDELETE /productos/5"Cancele el pedido N° 5"

Así se ve una conversación real. La app envía los datos en el body como JSON, y la API responde con un código y otro JSON:

JSON La app envía → POST http://localhost/api_ucv/productos 
{
  "nombre": "Inca Kola 500ml",
  "categoria": "Bebidas",
  "precio": 2.5,
  "stock": 24
}
JSON La API responde ← código 201 (Created) 
{
  "id": 7,
  "mensaje": "Producto creado"
}

El código de respuesta es un número que dice cómo le fue a la petición. Nuestra app lo revisa para saber si mostrar un mensaje verde o rojo:

CódigoSignificado¿Cuándo lo veremos?

201 CreatedSe creó algo nuevoRegistro de usuario, producto nuevo
401 UnauthorizedNo te reconozcoCorreo o contraseña incorrectos
404 Not FoundEso no existeRuta mal escrita, producto ya eliminado

Regla fácil: los 2xx son éxito, los 4xx son "te equivocaste tú" (la app envió algo mal) y los 5xx son "me equivoqué yo" (el servidor falló).

API · NUEVO models/Producto.php 
<?php
// models/Producto.php
// Todas las consultas SQL de la tabla producto viven aqui.

class Producto {

    private PDO $db;
    private string $table = 'producto';
    private string $campos = 'id, nombre, categoria, precio, stock, created_at';

    public function __construct(PDO $db) {
        $this->db = $db;
    }

    public function listar(): array {
        $stmt = $this->db->query(
            "SELECT {$this->campos} FROM {$this->table} ORDER BY nombre ASC"
        );
        return array_map([$this, 'tipar'], $stmt->fetchAll());
    }

    public function obtener(int $id): array|false {
        $stmt = $this->db->prepare(
            "SELECT {$this->campos} FROM {$this->table} WHERE id = ?"
        );
        $stmt->execute([$id]);
        $fila = $stmt->fetch();
        return $fila ? $this->tipar($fila) : false;
    }

    public function insertar(array $data): int {
        $stmt = $this->db->prepare(
            "INSERT INTO {$this->table} (nombre, categoria, precio, stock)
             VALUES (:nombre, :categoria, :precio, :stock)"
        );
        $stmt->execute([
            ':nombre'    => trim($data['nombre']),
            ':categoria' => trim($data['categoria']),
            ':precio'    => $data['precio'],
            ':stock'     => $data['stock'],
        ]);
        return (int) $this->db->lastInsertId();
    }

    public function actualizar(int $id, array $data): int {
        $stmt = $this->db->prepare(
            "UPDATE {$this->table}
             SET nombre = :nombre, categoria = :categoria, precio = :precio, stock = :stock
             WHERE id = :id"
        );
        $stmt->execute([
            ':nombre'    => trim($data['nombre']),
            ':categoria' => trim($data['categoria']),
            ':precio'    => $data['precio'],
            ':stock'     => $data['stock'],
            ':id'        => $id,
        ]);
        return $stmt->rowCount();
    }

    public function eliminar(int $id): int {
        $stmt = $this->db->prepare("DELETE FROM {$this->table} WHERE id = ?");
        $stmt->execute([$id]);
        return $stmt->rowCount();
    }

    // MySQL devuelve DECIMAL como texto ("4.50").
    // Lo convertimos a numero para que el JSON llegue limpio a Flutter.
    private function tipar(array $fila): array {
        $fila['id']     = (int) $fila['id'];
        $fila['precio'] = (float) $fila['precio'];
        $fila['stock']  = (int) $fila['stock'];
        return $fila;
    }
}
💡

¿Para qué sirve tipar()? MySQL entrega las columnas DECIMAL como texto: "4.50" en vez de 4.5. Si la API envía texto, Flutter recibe un String donde esperaba un número. Convertimos aquí para que el JSON salga limpio.

API · REEMPLAZAR models/Usuario.php 
<?php
// models/Usuario.php

class Usuario {

    private PDO $db;
    private string $table = 'usuario';

    // password excluido deliberadamente — nunca viaja al cliente
    private string $campos = 'id, nombre, apellido, email, telefono, activo, created_at';

    public function __construct(PDO $db) {
        $this->db = $db;
    }

    public function listar(): array {
        $stmt = $this->db->query(
            "SELECT {$this->campos} FROM {$this->table} ORDER BY id DESC"
        );
        return $stmt->fetchAll();
    }

    public function obtener(int $id): array|false {
        $stmt = $this->db->prepare(
            "SELECT {$this->campos} FROM {$this->table} WHERE id = ?"
        );
        $stmt->execute([$id]);
        return $stmt->fetch();
    }

    // NUEVO: ¿ya existe otro usuario con ese correo?
    // $excluirId sirve al editar: no se compara consigo mismo.
    public function existeEmail(string $email, ?int $excluirId = null): bool {
        $stmt = $this->db->prepare(
            "SELECT COUNT(*) FROM {$this->table} WHERE email = ? AND id <> ?"
        );
        $stmt->execute([$email, $excluirId ?? 0]);
        return (int) $stmt->fetchColumn() > 0;
    }

    // NUEVO: devuelve el usuario si el correo y la contraseña son correctos.
    // password_verify() compara lo escrito con el hash guardado.
    public function login(string $email, string $password): array|false {
        $stmt = $this->db->prepare(
            "SELECT {$this->campos}, password FROM {$this->table} WHERE email = ?"
        );
        $stmt->execute([$email]);
        $fila = $stmt->fetch();

        if (!$fila || !password_verify($password, $fila['password'])) {
            return false;
        }

        unset($fila['password']); // el hash tampoco sale de la API
        return $fila;
    }

    public function insertar(array $data): int {
        $hash = password_hash($data['password'], PASSWORD_BCRYPT);

        $stmt = $this->db->prepare(
            "INSERT INTO {$this->table} (nombre, apellido, email, password, telefono)
             VALUES (:nombre, :apellido, :email, :password, :telefono)"
        );
        $stmt->execute([
            ':nombre'   => trim($data['nombre']),
            ':apellido' => trim($data['apellido']),
            ':email'    => trim($data['email']),
            ':password' => $hash,
            ':telefono' => $data['telefono'] ?? null,
        ]);
        return (int) $this->db->lastInsertId();
    }

    public function actualizar(int $id, array $data): int {
        // Si viene password se hashea y actualiza; si no, se conserva el existente
        $sql = "UPDATE {$this->table}
                SET nombre = :nombre, apellido = :apellido, email = :email, telefono = :telefono";
        $params = [
            ':nombre'   => trim($data['nombre']),
            ':apellido' => trim($data['apellido']),
            ':email'    => trim($data['email']),
            ':telefono' => $data['telefono'] ?? null,
            ':id'       => $id,
        ];

        if (!empty($data['password'])) {
            $sql .= ", password = :password";
            $params[':password'] = password_hash($data['password'], PASSWORD_BCRYPT);
        }

        $stmt = $this->db->prepare($sql . " WHERE id = :id");
        $stmt->execute($params);
        return $stmt->rowCount();
    }

    public function eliminar(int $id): int {
        $stmt = $this->db->prepare("DELETE FROM {$this->table} WHERE id = ?");
        $stmt->execute([$id]);
        return $stmt->rowCount();
    }
}
🔐

¿Por qué no comparamos la contraseña con un WHERE password = ?? Porque en la base de datos no está la contraseña: está su hash (algo como $2y$10$Kq...). Un hash es como una huella digital: no se puede convertir de vuelta en la contraseña, pero password_verify() sí puede decir si lo escrito produce la misma huella.

API · REEMPLAZAR index.php 
<?php
// index.php — router principal de la API
// Rutas: /auth/login, /usuarios[/id], /productos[/id]

header("Content-Type: application/json; charset=UTF-8");
header("Access-Control-Allow-Origin: *");
header("Access-Control-Allow-Methods: GET, POST, PUT, DELETE, OPTIONS");
header("Access-Control-Allow-Headers: Content-Type, Authorization");

// Responder preflight CORS (lo envia Chrome antes de un POST/PUT/DELETE)
if ($_SERVER['REQUEST_METHOD'] === 'OPTIONS') {
    http_response_code(204);
    exit;
}

require_once 'config/Database.php';
require_once 'models/Usuario.php';
require_once 'models/Producto.php';

// Envia una respuesta JSON con su codigo HTTP y TERMINA el script (exit).
// Por eso, despues de responder() no hace falta escribir break ni return.
function responder(int $codigo, array $datos): never {
    http_response_code($codigo);
    echo json_encode($datos, JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES);
    exit;
}

$db     = (new Database())->getConnection();
$method = $_SERVER['REQUEST_METHOD'];

// Extraer segmentos de la URI limpiando el prefijo del proyecto
// Ejemplo Laragon: /api_ucv/productos/5  ->  ['productos', '5']
$uri      = trim(parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH), '/');
$segments = explode('/', $uri);

$projectFolder = 'api_ucv';
if (isset($segments[0]) && $segments[0] === $projectFolder) {
    array_shift($segments);
}

$resource = $segments[0] ?? '';
$accion   = $segments[1] ?? '';                              // ej: "login" o "5"
$id       = ctype_digit($accion) ? (int) $accion : null;   // solo si es numero

// Cuerpo JSON enviado por la app (POST / PUT)
$body = json_decode(file_get_contents("php://input"), true) ?? [];

// ----- Router -----
try {
    switch ($resource) {
        case 'auth':
            routeAuth(new Usuario($db), $method, $accion, $body);
            break;

        case 'usuarios':
            routeUsuarios(new Usuario($db), $method, $id, $body);
            break;

        case 'productos':
            routeProductos(new Producto($db), $method, $id, $body);
            break;

        default:
            responder(404, ['error' => 'Recurso no encontrado']);
    }
} catch (PDOException $e) {
    $debug = ($_ENV['APP_DEBUG'] ?? 'false') === 'true';
    responder(500, [
        'error'   => 'Error en la base de datos',
        'detalle' => $debug ? $e->getMessage() : null,
    ]);
}

// ----- Handlers -----

// POST /auth/login  { "email": "...", "password": "..." }
function routeAuth(Usuario $u, string $method, string $accion, array $body): void {
    if ($accion !== 'login' || $method !== 'POST') {
        responder(404, ['error' => 'Use POST /auth/login']);
    }
    if (empty($body['email']) || empty($body['password'])) {
        responder(422, ['error' => 'email y password son obligatorios']);
    }

    $usuario = $u->login(trim($body['email']), $body['password']);

    if (!$usuario) {
        responder(401, ['error' => 'Correo o contraseña incorrectos']);
    }
    if ((int) $usuario['activo'] !== 1) {
        responder(403, ['error' => 'Su cuenta está desactivada']);
    }
    responder(200, ['mensaje' => 'Bienvenido', 'usuario' => $usuario]);
}

function routeUsuarios(Usuario $u, string $method, ?int $id, array $body): void {
    switch ($method) {
        case 'GET':
            if ($id) {
                $data = $u->obtener($id);
                $data ? responder(200, $data)
                      : responder(404, ['error' => 'Usuario no encontrado']);
            }
            responder(200, $u->listar());

        case 'POST':
            if (empty($body['nombre']) || empty($body['apellido']) ||
                empty($body['email'])  || empty($body['password'])) {
                responder(422, ['error' => 'nombre, apellido, email y password son obligatorios']);
            }
            if ($u->existeEmail(trim($body['email']))) {
                responder(409, ['error' => 'Ese correo ya está registrado']);
            }
            $newId = $u->insertar($body);
            responder(201, ['id' => $newId, 'mensaje' => 'Usuario creado']);

        case 'PUT':
            if (!$id) {
                responder(400, ['error' => 'Se requiere el id en la URL']);
            }
            if (empty($body['nombre']) || empty($body['apellido']) || empty($body['email'])) {
                responder(422, ['error' => 'nombre, apellido y email son obligatorios']);
            }
            if (!$u->obtener($id)) {
                responder(404, ['error' => 'Usuario no encontrado']);
            }
            if ($u->existeEmail(trim($body['email']), $id)) {
                responder(409, ['error' => 'Ese correo ya está registrado']);
            }
            $u->actualizar($id, $body);
            responder(200, ['mensaje' => 'Usuario actualizado']);

        case 'DELETE':
            if (!$id) {
                responder(400, ['error' => 'Se requiere el id en la URL']);
            }
            $u->eliminar($id)
                ? responder(200, ['mensaje' => 'Usuario eliminado'])
                : responder(404, ['error' => 'Usuario no encontrado']);

        default:
            responder(405, ['error' => 'Metodo no permitido']);
    }
}

function routeProductos(Producto $p, string $method, ?int $id, array $body): void {
    switch ($method) {
        case 'GET':
            if ($id) {
                $data = $p->obtener($id);
                $data ? responder(200, $data)
                      : responder(404, ['error' => 'Producto no encontrado']);
            }
            responder(200, $p->listar());

        case 'POST':
            if ($error = validarProducto($body)) {
                responder(422, ['error' => $error]);
            }
            $newId = $p->insertar($body);
            responder(201, ['id' => $newId, 'mensaje' => 'Producto creado']);

        case 'PUT':
            if (!$id) {
                responder(400, ['error' => 'Se requiere el id en la URL']);
            }
            if ($error = validarProducto($body)) {
                responder(422, ['error' => $error]);
            }
            if (!$p->obtener($id)) {
                responder(404, ['error' => 'Producto no encontrado']);
            }
            $p->actualizar($id, $body);
            responder(200, ['mensaje' => 'Producto actualizado']);

        case 'DELETE':
            if (!$id) {
                responder(400, ['error' => 'Se requiere el id en la URL']);
            }
            $p->eliminar($id)
                ? responder(200, ['mensaje' => 'Producto eliminado'])
                : responder(404, ['error' => 'Producto no encontrado']);

        default:
            responder(405, ['error' => 'Metodo no permitido']);
    }
}

// Devuelve el texto del error, o null si el producto es valido
function validarProducto(array $b): ?string {
    if (trim($b['nombre'] ?? '') === '') {
        return 'El nombre es obligatorio';
    }
    if (trim($b['categoria'] ?? '') === '') {
        return 'La categoría es obligatoria';
    }
    if (!isset($b['precio']) || !is_numeric($b['precio']) || $b['precio'] < 0) {
        return 'El precio debe ser un número mayor o igual a 0';
    }
    if (!isset($b['stock']) || filter_var($b['stock'], FILTER_VALIDATE_INT) === false || $b['stock'] < 0) {
        return 'El stock debe ser un número entero mayor o igual a 0';
    }
    return null;
}

// ======================================================
// data/services/api_client.dart
// El "mensajero" de la app: es el UNICO archivo que usa
// el paquete http. Los services le piden: "lleva esto a
// la API y traeme la respuesta".
// ======================================================

// Error con un mensaje entendible para mostrar en un SnackBar
class ApiException implements Exception {
  const ApiException(this.mensaje);

  final String mensaje;

  @override
  String toString() => mensaje;
}

class ApiClient {
  // Le avisamos a la API que enviamos y esperamos JSON
  static const Map<String, String> _headers = {
    'Content-Type': 'application/json; charset=UTF-8',
    'Accept': 'application/json',
  };

  // ---------- Los 4 verbos HTTP ----------

  // GET: leer datos
  static Future<dynamic> get(String ruta) {
    return _enviar(() => http.get(ApiConfig.uri(ruta), headers: _headers));
  }

  // POST: crear algo nuevo (los datos viajan en el body)
  static Future<dynamic> post(String ruta, Map<String, dynamic> datos) {
    return _enviar(() => http.post(
          ApiConfig.uri(ruta),
          headers: _headers,
          body: jsonEncode(datos), // Map de Dart -> texto JSON
        ));
  }

  // PUT: modificar algo que ya existe
  static Future<dynamic> put(String ruta, Map<String, dynamic> datos) {
    return _enviar(() => http.put(
          ApiConfig.uri(ruta),
          headers: _headers,
          body: jsonEncode(datos),
        ));
  }

  // DELETE: eliminar
  static Future<dynamic> delete(String ruta) {
    return _enviar(() => http.delete(ApiConfig.uri(ruta), headers: _headers));
  }

  // ---------- Lo que tienen en comun los 4 ----------
  // Recibe la peticion "lista para enviar", la envia y revisa la respuesta.
  static Future<dynamic> _enviar(
    Future<http.Response> Function() peticion,
  ) async {
    final http.Response respuesta;

    // 1) Enviar. Aqui fallamos si no hay conexion con la API.
    try {
      respuesta = await peticion().timeout(ApiConfig.timeout);
    } on TimeoutException {
      throw const ApiException('La API tardo demasiado en responder');
    } on http.ClientException {
      throw const ApiException(
        'No se pudo conectar con la API. ¿Laragon esta encendido? ¿La URL es correcta?',
      );
    }

    // 2) Convertir el texto JSON en datos de Dart (Map o List)
    dynamic cuerpo;
    try {
      // utf8.decode respeta las tildes y la ñ
      cuerpo = respuesta.body.isEmpty
          ? null
          : jsonDecode(utf8.decode(respuesta.bodyBytes));
    } on FormatException {
      // Paso algo raro: PHP devolvio HTML (un error) en vez de JSON
      throw ApiException(
        'La API no respondio JSON (codigo ${respuesta.statusCode}). Revisen la URL o el PHP.',
      );
    }

    // 3) Codigos 200 a 299 = todo salio bien
    if (respuesta.statusCode >= 200 && respuesta.statusCode < 300) {
      return cuerpo;
    }

    // 4) Cualquier otro codigo es un error. Nuestra API siempre
    //    responde {"error": "..."}: usamos ese texto.
    if (cuerpo is Map && cuerpo['error'] != null) {
      throw ApiException(cuerpo['error'].toString());
    }
    throw ApiException('Error ${respuesta.statusCode} en la API');
  }
}

class Producto {
  final int? id; // null = producto nuevo, aun no guardado en la API
  final String nombre;
  final String categoria;
  final double precio;
  final int stock;

  const Producto({
    this.id,
    required this.nombre,
    required this.categoria,
    required this.precio,
    required this.stock,
  });

  bool get stockBajo => stock < 5;

  // JSON (Map) -> objeto Producto. Se usa al LEER de la API.
  factory Producto.fromJson(Map<String, dynamic> json) {
    return Producto(
      id: int.parse(json['id'].toString()),
      nombre: json['nombre'] ?? '',
      categoria: json['categoria'] ?? '',
      // MySQL a veces envia el precio como texto ("4.50"):
      // con toString() + parse funciona en los dos casos.
      precio: double.parse(json['precio'].toString()),
      stock: int.parse(json['stock'].toString()),
    );
  }

  // Objeto Producto -> Map. Se usa al ENVIAR a la API (POST y PUT).
  // El id no se envia: va en la URL (/productos/5).
  Map<String, dynamic> toJson() {
    return {
      'nombre': nombre,
      'categoria': categoria,
      'precio': precio,
      'stock': stock,
    };
  }

// ======================================================
// data/services/producto_service.dart
// El CRUD completo de productos:
//   C = crear (POST)   R = leer (GET)
//   U = actualizar (PUT)   D = eliminar (DELETE)
// ======================================================

class ProductoService {
  // GET /productos -> la API responde una LISTA de Maps
  Future<List<Producto>> listar() async {
    final List datos = await ApiClient.get('/productos');
    // map() convierte CADA Map en un Producto
    return datos.map((item) => Producto.fromJson(item)).toList();
  }

  // POST /productos
  Future<void> crear(Producto producto) async {
    await ApiClient.post('/productos', producto.toJson());
  }

  // PUT /productos/5
  Future<void> actualizar(Producto producto) async {
    await ApiClient.put('/productos/${producto.id}', producto.toJson());
  }

  // DELETE /productos/5
  Future<void> eliminar(int id) async {
    await ApiClient.delete('/productos/$id');
  }
}

// ======================================================
// core/validators.dart
// Funciones que revisan si lo que escribio el usuario
// es correcto. Las usaremos en el Login Y en el Registro,
// por eso viven aqui y no dentro de un formulario.
//
// Regla de TODO validator:
//   - devuelve null      -> el campo esta bien
//   - devuelve un String -> ese texto aparece en rojo
// ======================================================

class Validators {
  // 1) Campo obligatorio: no puede quedar vacio
  static String? obligatorio(String? valor) {
    // trim() quita los espacios: "   " tambien cuenta como vacio
    if (valor == null || valor.trim().isEmpty) {
      return 'Este campo es obligatorio';
    }
    return null; // null = sin error
  }

  // 2) Correo electronico
  static String? email(String? valor) {
    // Primero revisamos que no este vacio (reutilizamos la funcion 1)
    final error = obligatorio(valor);
    if (error != null) return error;

    // RegExp = un "molde" que el texto debe cumplir:
    //   letras/numeros  @  dominio  .  com / pe / edu ...
    final molde = RegExp(r'^[\w\.\-]+@([\w\-]+\.)+[a-zA-Z]{2,4}$');

    // valor! -> el "!" le dice a Dart: "tranquilo, aqui no es null"
    if (!molde.hasMatch(valor!.trim())) {
      return 'Correo electronico invalido';
    }
    return null;
  }

  // 3) Contraseña segura: 8 caracteres, una MAYUSCULA y un numero
  static String? password(String? valor) {
    final error = obligatorio(valor);
    if (error != null) return error;

    if (valor!.length < 8) {
      return 'Debe tener 8 caracteres como minimo';
    }
    // contains(RegExp(...)) pregunta: "¿hay al menos uno de estos?"
    if (!valor.contains(RegExp(r'[A-Z]'))) {
      return 'Debe tener al menos una letra MAYUSCULA';
    }
    if (!valor.contains(RegExp(r'[0-9]'))) {
      return 'Debe tener al menos un numero';
    }
    return null;
  }

  // 4) Repetir contraseña: debe ser igual a la primera
  //    Recibe 2 datos: lo escrito y la contraseña original
  static String? confirmar(String? valor, String original) {
    final error = obligatorio(valor);
    if (error != null) return error;

    if (valor != original) {
      return 'Las contraseñas no coinciden';
    }
    return null;
  }

  // 5) NUEVO (Sesion 3) Precio: numero con decimales, 0 o mas
  static String? precio(String? valor) {
    final error = obligatorio(valor);
    if (error != null) return error;

    // tryParse devuelve null si el texto NO es un numero.
    // Aceptamos coma o punto: "4,50" y "4.50"
    final numero = double.tryParse(valor!.trim().replaceAll(',', '.'));
    if (numero == null) {
      return 'Escriba un precio valido, ej: 4.50';
    }
    if (numero < 0) {
      return 'El precio no puede ser negativo';
    }
    return null;
  }

  // 6) NUEVO (Sesion 3) Stock: numero entero, 0 o mas
  static String? stock(String? valor) {
    final error = obligatorio(valor);
    if (error != null) return error;

    final numero = int.tryParse(valor!.trim());
    if (numero == null) {
      return 'Escriba un numero entero, ej: 10';
    }
    if (numero < 0) {
      return 'El stock no puede ser negativo';
    }
    return null;
  }
}

import 'package:flutter/material.dart';
import 'package:app_flutter/data/models/producto.dart';

// Version final: listar, crear, editar y eliminar con la API
class HomeScreen extends StatefulWidget {
  const HomeScreen({super.key, required this.usuario});

  final Usuario usuario;

  @override
  State<HomeScreen> createState() => _HomeScreenState();
}

class _HomeScreenState extends State<HomeScreen> {
  int currentScreenIndex = 0;

  final productoService = ProductoService();

  List<Producto> productos = []; // DATA
  bool cargando = true;          // LOADING
  String? error;                 // ERROR

  @override
  void initState() {
    super.initState();
    cargarProductos();
  }

  Future<void> cargarProductos() async {
    try {
      final lista = await productoService.listar();
      if (!mounted) return;
      setState(() {
        productos = lista;
        error = null;
        cargando = false;
      });
    } on ApiException catch (e) {
      if (!mounted) return;
      setState(() {
        error = e.mensaje;
        cargando = false;
      });
    }
  }

  void reintentar() {
    setState(() {
      cargando = true;
      error = null;
    });
    cargarProductos();
  }

  // ---------- NUEVO: crear y editar ----------
  // Sin producto -> formulario vacio (crear).
  // Con producto -> formulario lleno (editar).
  Future<void> abrirFormulario([Producto? producto]) async {
    // push<bool> = esperamos que la otra pantalla nos DEVUELVA un bool
    final guardo = await Navigator.of(context).push<bool>(
      MaterialPageRoute(builder: (_) => ProductoFormScreen(producto: producto)),
    );

    // guardo es true solo si el formulario hizo pop(context, true)
    if (guardo != true || !mounted) return;

    mostrarMensaje(
      producto == null ? 'Producto creado' : 'Producto actualizado',
      Colors.green,
    );
    cargarProductos(); // pedimos la lista otra vez: la API manda
  }

  // ---------- NUEVO: eliminar ----------
  Future<void> eliminarProducto(Producto producto) async {
    // showDialog tambien DEVUELVE lo que se envia con pop
    final confirmar = await showDialog<bool>(
      context: context,
      builder: (ctx) => AlertDialog(
        title: const Text('Eliminar producto'),
        content: Text('¿Seguro que desea eliminar "${producto.nombre}"?'),
        actions: [
          TextButton(
            onPressed: () => Navigator.pop(ctx, false),
            child: const Text('Cancelar'),
          ),
          FilledButton(
            style: FilledButton.styleFrom(backgroundColor: Colors.red),
            onPressed: () => Navigator.pop(ctx, true),
            child: const Text('Eliminar'),
          ),
        ],
      ),
    );

    if (confirmar != true) return; // cancelo o toco fuera del dialogo

    try {
      await productoService.eliminar(producto.id!);
      if (!mounted) return;
      mostrarMensaje('Producto eliminado', Colors.green);
      cargarProductos();
    } on ApiException catch (e) {
      if (!mounted) return;
      mostrarMensaje(e.mensaje, Colors.red);
    }
  }

  void mostrarMensaje(String texto, Color color) {
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(
        content: Text(texto, style: const TextStyle(color: Colors.white)),
        backgroundColor: color,
        behavior: SnackBarBehavior.floating,
      ),
    );
  }

  Widget vistaProductos(List<Producto> lista) {
    if (cargando) {
      return const Center(child: CircularProgressIndicator());
    }
    if (error != null) {
      return Center(
        child: Padding(
          padding: const EdgeInsets.all(24),
          child: Column(
            mainAxisSize: MainAxisSize.min,
            children: [
              const Icon(Icons.cloud_off, size: 64, color: Colors.black38),
              const SizedBox(height: 12),
              Text(error!, textAlign: TextAlign.center),
              const SizedBox(height: 16),
              FilledButton.icon(
                onPressed: reintentar,
                icon: const Icon(Icons.refresh),
                label: const Text('Reintentar'),
              ),
            ],
          ),
        ),
      );
    }
    return ProductosView(
      productos: lista,
      onRefresh: cargarProductos,
      onTap: (producto) => abrirFormulario(producto), // tocar = editar
      onEliminar: eliminarProducto,                    // papelera = eliminar
    );
  }

  @override
  Widget build(BuildContext context) {
    final productosBajos = productos.where((p) => p.stockBajo).toList();

    final vistas = [
      vistaProductos(productos),
      vistaProductos(productosBajos),
      PerfilView(usuario: widget.usuario),
    ];

    return Scaffold(
      appBar: AppBar(title: const Text('Inventario MiBodega')),
      body: vistas[currentScreenIndex],
      bottomNavigationBar: NavigationBar(
        selectedIndex: currentScreenIndex,
        onDestinationSelected: (index) {
          setState(() => currentScreenIndex = index);
        },
        labelBehavior: NavigationDestinationLabelBehavior.onlyShowSelected,
        destinations: [
          const NavigationDestination(
            icon: Icon(Icons.inventory_2_outlined),
            label: 'Productos',
          ),
          NavigationDestination(
            icon: Badge(
              label: Text('${productosBajos.length}'),
              child: const Icon(Icons.warning_amber_outlined),
            ),
            label: 'Stock bajo',
          ),
          const NavigationDestination(
            icon: Icon(Icons.person_outline),
            label: 'Perfil',
          ),
        ],
      ),
      // El boton + vuelve, pero ahora abre el formulario
      floatingActionButton: currentScreenIndex == 0
          ? FloatingActionButton(
              onPressed: () => abrirFormulario(),
              child: const Icon(Icons.add),
            )
          : null,
    );
  }
}

"La API manda". Después de crear, editar o eliminar, no tocamos la lista a mano: llamamos a cargarProductos() y dibujamos lo que diga la base de datos. Así, si otro compañero agregó productos desde su celular, también aparecen.
