SQLite básico: tabla de países

Insertar, actualizar y eliminar registros en una base de datos local. Un formulario sencillo trabaja sobre la tabla paises del proyecto com.example.sqlitepaises.

Antes de empezar: ¿qué es SQLite?

SQLite es un motor de base de datos relacional (tablas con filas y columnas, consultadas con SQL) que funciona dentro de la propia aplicación. No necesita un servidor, ni instalación, ni usuario y contraseña: toda la base de datos es un solo archivo guardado en el dispositivo.

En una frase: SQLite es como tener una pequeña base de datos MySQL guardada en un archivo dentro del celular, que solo tu app puede leer y escribir, y que funciona sin internet.

¿Cómo se maneja?

Base de datos cliente-servidor

MySQL, PostgreSQL, SQL Server. La app envía las consultas por la red a un servidor que guarda los datos.

App → internet → servidor → disco

Necesita conexión, un servidor encendido y credenciales.

SQLite (embebida)

La app usa una biblioteca incluida en Android que lee y escribe directamente el archivo .db.

App → SQLite → archivo paises.db

Sin red, sin servidor, sin configuración.

Característica Detalle
Dónde vive En Android: /data/data/com.example.sqlitepaises/databases/paises.db. Es privada: otras apps no pueden abrirla.
Lenguaje SQL estándar: CREATE TABLE, INSERT, SELECT, UPDATE, DELETE.
Tipos de datos Solo cinco: NULL, INTEGER, REAL, TEXT y BLOB. No hay booleano ni fecha: se guardan como número o texto.
Confiabilidad Transacciones ACID: si la app se cierra a mitad de una escritura, los datos no quedan corruptos.
Desde Android Con SQLiteOpenHelper (esta guía) o con Room, la biblioteca recomendada por Google, que se construye sobre SQLite.
Origen Creada por D. Richard Hipp en el año 2000. Es de dominio público: gratuita para cualquier uso.

¿Quién lo usa?

SQLite es el motor de base de datos más usado del mundo: sus creadores estiman más de un billón de bases de datos SQLite en uso. Probablemente tu celular tiene cientos en este momento.

Sistemas operativos

Android e iOS

Los contactos, los mensajes SMS, el calendario y el registro de llamadas se guardan en bases SQLite.

Mensajería

WhatsApp

El historial de chats se almacena localmente en una base SQLite; por eso puedes leer tus mensajes sin conexión.

Navegadores

Chrome y Firefox

Historial, marcadores, cookies y contraseñas guardadas se manejan con archivos SQLite.

Apps de escritorio

Programas instalados

Editores de fotos, reproductores de música y gestores de notas guardan sus catálogos y configuraciones en SQLite.

Lenguajes

Python, PHP, Node.js

Incluyen soporte para SQLite: se usa mucho para prototipos, pruebas y aplicaciones pequeñas.

Dispositivos

Televisores, autos, IoT

Sistemas embebidos que necesitan guardar datos sin un servidor usan SQLite por su tamaño reducido.

¿Cuándo usarlo?

Úsalo cuando…

  • Los datos pertenecen a un solo usuario y dispositivo: notas, tareas, gastos, favoritos.
  • La app debe funcionar sin internet.
  • Necesitas guardar una copia local de datos que llegan de una API para mostrarlos rápido.
  • Los datos tienen estructura: varias columnas, búsquedas, filtros u ordenamiento.

No es la mejor opción cuando…

  • Varios usuarios deben ver y modificar los mismos datos en tiempo real: usa un servidor (MySQL + API) o Firebase.
  • Solo guardas un par de valores sueltos (tema oscuro, último usuario): basta con SharedPreferences.
  • Guardas archivos grandes (fotos, videos): van en el almacenamiento de archivos; en la BD solo su ruta.

2. Conceptos clave

SQLite es una base de datos que vive en un archivo dentro del teléfono. Los datos se conservan aunque cierres la app o apagues el dispositivo, y funciona sin internet.

Base de datos

Archivo paises.db guardado en la memoria interna de la app.

Tabla

paises: filas (registros) y columnas (campos).

SQLiteOpenHelper

Clase de Android que crea la BD y la tabla, y controla las versiones.

Modelo

Pais: un objeto Kotlin por cada fila.

Formulario → MainActivity → PaisDbHelper → SQL → paises.db

2.1 Las operaciones de la guía

Operación SQL Método de Android Devuelve
Insertar INSERT INTO paises … db.insert() El id generado, o -1 si falla
Actualizar UPDATE paises SET … WHERE id_pais = ? db.update() Cantidad de filas modificadas
Eliminar DELETE FROM paises WHERE id_pais = ? db.delete() Cantidad de filas eliminadas
Consultar (apoyo) SELECT * FROM paises … db.rawQuery() Un Cursor para recorrer filas
¿Por qué consultar si el tema es insertar, actualizar y eliminar? Para actualizar o eliminar necesitas conocer el id_pais del registro. Una búsqueda por id y un listado simple en pantalla te permiten ver el efecto de cada operación.

3.1 Decisiones de diseño

estado INTEGER

¿Por qué 1 y 0?

SQLite no tiene tipo booleano. Se usa INTEGER con 1/0, que se asocia directamente a un CheckBox.

UNIQUE

Sin duplicados

La base de datos rechaza un segundo «Perú». Así el control no depende solo del código Kotlin.

AUTOINCREMENT

Ids que no se reutilizan

Si eliminas el país 3, el siguiente será el 4. Un id eliminado no vuelve a asignarse.

Eliminación física vs. lógica: DELETE borra la fila para siempre (eliminación física). Cambiar estado a 0 la «desactiva» pero conserva el dato (eliminación lógica). Muchas apps reales prefieren la lógica para no perder historial. En esta guía practicarás las dos.

4.2 Helper con la tabla

Clic derecho en el paquete data → New → Kotlin Class/File → PaisDbHelper.

package com.example.sqlitepaises.data

import android.content.Context
import android.database.sqlite.SQLiteDatabase
import android.database.sqlite.SQLiteOpenHelper
import android.util.Log

class PaisDbHelper(context: Context) :
    SQLiteOpenHelper(context, DB_NAME, null, DB_VERSION) {

    companion object {
        // Etiqueta para filtrar en Logcat
        const val TAG = "SQLitePaises"

        // Archivo de la base de datos y su versión
        const val DB_NAME = "paises.db"
        const val DB_VERSION = 1

        // Tabla y columnas
        const val TABLE_PAISES = "paises"
        const val COL_ID = "id_pais"
        const val COL_NOMBRE = "nombre"
        const val COL_ESTADO = "estado"
    }

    // Se ejecuta UNA sola vez: cuando la base de datos todavía no existe
    override fun onCreate(db: SQLiteDatabase) {
        val sql = """
            CREATE TABLE $TABLE_PAISES (
                $COL_ID INTEGER PRIMARY KEY AUTOINCREMENT,
                $COL_NOMBRE TEXT NOT NULL UNIQUE,
                $COL_ESTADO INTEGER NOT NULL DEFAULT 1
            )
        """.trimIndent()

        db.execSQL(sql)
        Log.d(TAG, "onCreate(): tabla $TABLE_PAISES creada")
    }

    // Se ejecuta cuando aumentas DB_VERSION
    override fun onUpgrade(db: SQLiteDatabase, oldVersion: Int, newVersion: Int) {
        Log.d(TAG, "onUpgrade(): de la versión $oldVersion a la $newVersion")
        db.execSQL("DROP TABLE IF EXISTS $TABLE_PAISES")
        onCreate(db)
    }
}
Parte Función
SQLiteOpenHelper(context, DB_NAME, null, DB_VERSION) Indica el archivo de la BD y su versión.
companion object Constantes con los nombres de tabla y columnas: evitan errores de escritura.
onCreate() Crea la tabla la primera vez. execSQL() ejecuta la sentencia.
onUpgrade() Rehace la tabla al subir la versión. Borra los datos: úsalo solo en práctica.

5. CRUD en el helper

Reemplaza PaisDbHelper.kt. Se agregan los métodos para insertar, actualizar y eliminar, más dos consultas de apoyo:

package com.example.sqlitepaises.data

import android.content.ContentValues
import android.content.Context
import android.database.sqlite.SQLiteConstraintException
import android.database.sqlite.SQLiteDatabase
import android.database.sqlite.SQLiteOpenHelper
import android.util.Log
import com.example.sqlitepaises.model.Pais

class PaisDbHelper(context: Context) :
    SQLiteOpenHelper(context, DB_NAME, null, DB_VERSION) {

    companion object {
        const val TAG = "SQLitePaises"
        const val DB_NAME = "paises.db"
        const val DB_VERSION = 1

        const val TABLE_PAISES = "paises"
        const val COL_ID = "id_pais"
        const val COL_NOMBRE = "nombre"
        const val COL_ESTADO = "estado"
    }

    override fun onCreate(db: SQLiteDatabase) {
        val sql = """
            CREATE TABLE $TABLE_PAISES (
                $COL_ID INTEGER PRIMARY KEY AUTOINCREMENT,
                $COL_NOMBRE TEXT NOT NULL UNIQUE,
                $COL_ESTADO INTEGER NOT NULL DEFAULT 1
            )
        """.trimIndent()

        db.execSQL(sql)
        Log.d(TAG, "onCreate(): tabla $TABLE_PAISES creada")
    }

    override fun onUpgrade(db: SQLiteDatabase, oldVersion: Int, newVersion: Int) {
        Log.d(TAG, "onUpgrade(): de la versión $oldVersion a la $newVersion")
        db.execSQL("DROP TABLE IF EXISTS $TABLE_PAISES")
        onCreate(db)
    }

    // ===================== INSERTAR =====================
    // Devuelve el id generado, o -1 si falla (por ejemplo, nombre repetido)
    fun insertar(pais: Pais): Long {
        val db = writableDatabase

        // ContentValues: pares columna → valor. El id no se envía: lo genera SQLite
        val valores = ContentValues().apply {
            put(COL_NOMBRE, pais.nombre)
            put(COL_ESTADO, pais.estado)
        }

        val id = db.insert(TABLE_PAISES, null, valores)
        Log.d(TAG, "insertar(): ${pais.nombre} → id = $id")
        db.close()
        return id
    }

    // ===================== ACTUALIZAR =====================
    // Devuelve filas modificadas: 1 = OK, 0 = no existe ese id, -1 = nombre repetido
    fun actualizar(pais: Pais): Int {
        val db = writableDatabase

        val valores = ContentValues().apply {
            put(COL_NOMBRE, pais.nombre)
            put(COL_ESTADO, pais.estado)
        }

        val filas = try {
            // WHERE id_pais = ?  → el ? se reemplaza por el valor del arreglo
            db.update(TABLE_PAISES, valores, "$COL_ID = ?", arrayOf(pais.idPais.toString()))
        } catch (e: SQLiteConstraintException) {
            // UNIQUE: ya existe otro país con ese nombre
            -1
        }

        Log.d(TAG, "actualizar(): id = ${pais.idPais} → filas = $filas")
        db.close()
        return filas
    }

    // ===================== ELIMINAR =====================
    // Devuelve filas eliminadas: 1 = OK, 0 = no existe ese id
    fun eliminar(idPais: Int): Int {
        val db = writableDatabase
        val filas = db.delete(TABLE_PAISES, "$COL_ID = ?", arrayOf(idPais.toString()))
        Log.d(TAG, "eliminar(): id = $idPais → filas = $filas")
        db.close()
        return filas
    }

    // ===================== CONSULTAS DE APOYO =====================
    // Busca un país por su id; devuelve null si no existe
    fun buscarPorId(idPais: Int): Pais? {
        val db = readableDatabase
        val cursor = db.rawQuery(
            "SELECT * FROM $TABLE_PAISES WHERE $COL_ID = ?",
            arrayOf(idPais.toString())
        )

        var pais: Pais? = null
        if (cursor.moveToFirst()) {
            pais = Pais(
                idPais = cursor.getInt(cursor.getColumnIndexOrThrow(COL_ID)),
                nombre = cursor.getString(cursor.getColumnIndexOrThrow(COL_NOMBRE)),
                estado = cursor.getInt(cursor.getColumnIndexOrThrow(COL_ESTADO))
            )
        }

        cursor.close()
        db.close()
        return pais
    }

    // Devuelve todos los países ordenados por id
    fun listar(): List<Pais> {
        val lista = mutableListOf<Pais>()
        val db = readableDatabase
        val cursor = db.rawQuery("SELECT * FROM $TABLE_PAISES ORDER BY $COL_ID", null)

        if (cursor.moveToFirst()) {
            do {
                lista.add(
                    Pais(
                        idPais = cursor.getInt(cursor.getColumnIndexOrThrow(COL_ID)),
                        nombre = cursor.getString(cursor.getColumnIndexOrThrow(COL_NOMBRE)),
                        estado = cursor.getInt(cursor.getColumnIndexOrThrow(COL_ESTADO))
                    )
                )
            } while (cursor.moveToNext())
        }

        cursor.close()
        db.close()
        return lista
    }
}

5.1 Cómo funciona cada método

insertar()

INSERT

Arma un ContentValues con nombre y estado. db.insert() devuelve el nuevo id_pais, o -1 si el nombre ya existe.

actualizar()

UPDATE

Cambia nombre y estado solo en la fila con ese id (WHERE id_pais = ?). Si el nombre choca con otro país, captura el error y devuelve -1.

eliminar()

DELETE

Borra la fila con ese id. Devuelve 1 si la eliminó y 0 si no existía.

El signo ?: es un parámetro. El valor real va aparte en arrayOf(...). Así Android escapa las comillas y evita la inyección SQL. Nunca concatenes lo que escribe el usuario dentro del SQL.
¡Cuidado con el WHERE! db.delete(TABLE_PAISES, null, null) sin condición borra todos los países. Lo mismo pasa con update sin WHERE: modifica todas las filas.

7. MainActivity: conectar botones y BD

Reemplaza MainActivity.kt:

package com.example.sqlitepaises

import android.os.Bundle
import android.widget.Button
import android.widget.CheckBox
import android.widget.EditText
import android.widget.TextView
import android.widget.Toast
import androidx.appcompat.app.AlertDialog
import androidx.appcompat.app.AppCompatActivity
import com.example.sqlitepaises.data.PaisDbHelper
import com.example.sqlitepaises.model.Pais

class MainActivity : AppCompatActivity() {

    private lateinit var dbHelper: PaisDbHelper
    private lateinit var etIdPais: EditText
    private lateinit var etNombre: EditText
    private lateinit var cbEstado: CheckBox
    private lateinit var tvListado: TextView

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)

        dbHelper = PaisDbHelper(this)

        etIdPais = findViewById(R.id.etIdPais)
        etNombre = findViewById(R.id.etNombre)
        cbEstado = findViewById(R.id.cbEstado)
        tvListado = findViewById(R.id.tvListado)

        findViewById<Button>(R.id.btnGuardar).setOnClickListener { guardar() }
        findViewById<Button>(R.id.btnActualizar).setOnClickListener { actualizar() }
        findViewById<Button>(R.id.btnEliminar).setOnClickListener { confirmarEliminar() }
        findViewById<Button>(R.id.btnBuscar).setOnClickListener { buscar() }
        findViewById<Button>(R.id.btnLimpiar).setOnClickListener { limpiar() }

        listar()
    }

    // ===================== INSERTAR =====================
    private fun guardar() {
        val nombre = leerNombre() ?: return
        val pais = Pais(nombre = nombre, estado = leerEstado())

        val id = dbHelper.insertar(pais)
        if (id == -1L) {
            mensaje("No se pudo guardar: «$nombre» ya existe")
        } else {
            mensaje("País guardado con id $id")
            limpiar()
            listar()
        }
    }

    // ===================== ACTUALIZAR =====================
    private fun actualizar() {
        val id = leerId() ?: return
        val nombre = leerNombre() ?: return
        val pais = Pais(idPais = id, nombre = nombre, estado = leerEstado())

        when (dbHelper.actualizar(pais)) {
            -1 -> mensaje("Ya existe otro país llamado «$nombre»")
            0 -> mensaje("No existe un país con id $id")
            else -> {
                mensaje("País $id actualizado")
                limpiar()
                listar()
            }
        }
    }

    // ===================== ELIMINAR =====================
    private fun confirmarEliminar() {
        val id = leerId() ?: return

        // Pedir confirmación: la eliminación no se puede deshacer
        AlertDialog.Builder(this)
            .setTitle("Eliminar país")
            .setMessage("¿Eliminar el país con id $id?")
            .setPositiveButton("Eliminar") { _, _ ->
                if (dbHelper.eliminar(id) > 0) {
                    mensaje("País $id eliminado")
                    limpiar()
                    listar()
                } else {
                    mensaje("No existe un país con id $id")
                }
            }
            .setNegativeButton("Cancelar", null)
            .show()
    }

    // ===================== APOYO =====================
    // Carga en el formulario el país del id indicado
    private fun buscar() {
        val id = leerId() ?: return
        val pais = dbHelper.buscarPorId(id)

        if (pais == null) {
            mensaje("No existe un país con id $id")
        } else {
            etNombre.setText(pais.nombre)
            cbEstado.isChecked = pais.estado == 1
        }
    }

    // Muestra todos los registros en el TextView
    private fun listar() {
        val paises = dbHelper.listar()
        tvListado.text = if (paises.isEmpty()) {
            "Sin registros"
        } else {
            paises.joinToString("\n") { "${it.idPais} | ${it.nombre} | ${it.estadoTexto()}" }
        }
    }

    private fun limpiar() {
        etIdPais.text.clear()
        etNombre.text.clear()
        cbEstado.isChecked = true
        etIdPais.requestFocus()
    }

    // ===================== VALIDACIONES =====================
    // Devuelve el id escrito o null (y marca el error) si no es un número
    private fun leerId(): Int? {
        val id = etIdPais.text.toString().trim().toIntOrNull()
        if (id == null) etIdPais.error = "Ingresa un id válido"
        return id
    }

    // Devuelve el nombre o null (y marca el error) si está vacío
    private fun leerNombre(): String? {
        val nombre = etNombre.text.toString().trim()
        if (nombre.isEmpty()) {
            etNombre.error = "Ingresa el nombre"
            return null
        }
        return nombre
    }

    // CheckBox marcado = 1, desmarcado = 0
    private fun leerEstado(): Int = if (cbEstado.isChecked) 1 else 0

    private fun mensaje(texto: String) {
        Toast.makeText(this, texto, Toast.LENGTH_SHORT).show()
    }
}

Actualizar Id + nombre (+ estado) dbHelper.actualizar() Limpia y lista
Eliminar Id Confirmación → dbHelper.eliminar() Limpia y lista
Buscar Id dbHelper.buscarPorId() Llena el formulario
leerId() ?: return: el operador Elvis ?: sale de la función si la validación devuelve null. Así cada botón se detiene solo cuando falta un dato, sin if anidados.

9. Errores comunes

Síntoma Causa Solución
no such table: paises Cambiaste el CREATE TABLE pero la BD ya existía, así que onCreate() no se volvió a ejecutar. Sube DB_VERSION a 2, o desinstala la app del emulador y vuelve a ejecutar.
insert() devuelve -1 El nombre ya existe (UNIQUE) o falta un campo NOT NULL. Revisa Logcat: aparece el error de SQLite con el detalle.
La app se cierra al actualizar update() lanza SQLiteConstraintException con un nombre repetido. Capturarla con try/catch, como hace actualizar().
Se modificaron o borraron todas las filas update o delete sin WHERE. Siempre pasa "id_pais = ?" y el id.
column index out of range o -1 El nombre de la columna no coincide. Usa las constantes COL_ID, COL_NOMBRE, COL_ESTADO.
