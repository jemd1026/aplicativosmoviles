Guía práctica

Spinner en Android con Kotlin

Todas las prácticas se realizan en la actividad SpinnerActivity y su layout activity_spinner.xml, dentro del paquete com.example.spinnerlistrecycler.

1. Preparar el proyecto

Trabaja en un proyecto con el paquete com.example.spinnerlistrecycler. Los archivos utilizados en la guía son:

app/src/main │ ├── java/com/example/spinnerlistrecycler │ ├── MainActivity.kt │ └── SpinnerActivity.kt ← se crea en esta guía │ ├── res/layout │ ├── activity_main.xml │ └── activity_spinner.xml ← se crea en esta guía │ ├── res/values │ └── arrays.xml ← se crea en la Parte 4 │ └── AndroidManifest.xml

1.1 Crear SpinnerActivity

  1. En el panel Project, haz clic derecho en el paquete com.example.spinnerlistrecycler.
  2. Selecciona New → Activity → Empty Views Activity.
  3. En Activity Name escribe SpinnerActivity. El campo Layout Name se completa como activity_spinner.
  4. Verifica que Language sea Kotlin y pulsa Finish.

1.2 Abrir SpinnerActivity al iniciar la app

En AndroidManifest.xml, mueve el intent-filter de MainActivity a SpinnerActivity. Así la app abre directamente la actividad de la práctica.

<activity
    android:name=".SpinnerActivity"
    android:exported="true">
    <intent-filter>
        <action android:name="android.intent.action.MAIN" />
        <category android:name="android.intent.category.LAUNCHER" />
    </intent-filter>
</activity>

<activity
    android:name=".MainActivity"
    android:exported="false" />
Importante: cada práctica reemplaza el contenido completo de activity_spinner.xml y SpinnerActivity.kt. Usa el botón Copiar de cada bloque y pega el código en Android Studio.

2. ¿Qué es un Spinner?

Un Spinner es un componente que permite seleccionar un valor de un conjunto. Equivale a una lista desplegable (dropdown) de una página web: muestra el elemento seleccionado y, al tocarlo, despliega las opciones disponibles.

🇵🇪 Perú▼
Estado cerrado
🇵🇪 Perú▲
🇨🇴 Colombia
🇦🇷 Argentina
🇨🇱 Chile
🇲🇽 México
Estado desplegado

Cuándo usarlo

  • Formularios de registro (país, ciudad, género).
  • Configuraciones (tema, idioma).
  • Filtros de búsqueda (categorías, orden).
  • Conversores (monedas, unidades).

Cuándo no usarlo

  • Más de 20–30 opciones: mejor una lista con búsqueda.
  • Varios datos por elemento: usa ListView o RecyclerView.
  • Selección múltiple: usa CheckBox.
  • Solo 2–3 opciones: usa RadioButton.

2.1 Componentes que intervienen

Spinner

Componente visual declarado en el layout.

ArrayAdapter

Conecta los datos (un arreglo) con el Spinner.

Layouts de ítem

simple_spinner_item (cerrado) y simple_spinner_dropdown_item (desplegado).

Característica Spinner ListView
Ítems visibles 1 (el seleccionado) Varios
Espacio en pantalla Muy pequeño Grande

Desplazamiento Solo al desplegar Siempre

3. Primer Spinner

Android proporciona dos layouts predefinidos para el Spinner:

Layout Se usa para Características
android.R.layout.simple_spinner_item El ítem seleccionado (Spinner cerrado) TextView compacto, sin padding extra.
android.R.layout.simple_spinner_dropdown_item Los ítems de la lista desplegada Más padding, efecto de selección, optimizado para toque.

3.2 Actividad

package com.example.spinnerlistrecycler

import android.os.Bundle
import android.view.View
import android.widget.AdapterView
import android.widget.ArrayAdapter
import android.widget.Spinner
import android.widget.TextView
import androidx.appcompat.app.AppCompatActivity

class SpinnerActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_spinner)

        // 1. Referenciar las vistas
        val spinner = findViewById<Spinner>(R.id.spinner)
        val tvSeleccion = findViewById<TextView>(R.id.tvSeleccion)

        // 2. Datos escritos directamente en el código
        val frutas = arrayOf(
            "🍎 Manzana",
            "🍌 Plátano",
            "🍊 Naranja",
            "🍇 Uva",
            "🍉 Sandía"
        )

        // 3. Crear el adapter (layout del ítem seleccionado)
        val adapter = ArrayAdapter(
            this,
            android.R.layout.simple_spinner_item,
            frutas
        )

        // 4. Layout de los ítems de la lista desplegada
        adapter.setDropDownViewResource(android.R.layout.simple_spinner_dropdown_item)

        // 5. Conectar el adapter con el Spinner
        spinner.adapter = adapter

        // 6. Escuchar la selección del usuario
        spinner.onItemSelectedListener = object : AdapterView.OnItemSelectedListener {
            override fun onItemSelected(parent: AdapterView<*>?, view: View?, position: Int, id: Long) {
                val frutaSeleccionada = parent?.getItemAtPosition(position).toString()
                tvSeleccion.text = "Selección: $frutaSeleccionada"
            }

            override fun onNothingSelected(parent: AdapterView<*>?) {
                tvSeleccion.text = "Selección: Ninguna"
            }
        }
    }
}

Resultado al elegir «Uva»:

Selección: 🍇 Uva
Nota: setDropDownViewResource() define cómo se ven los ítems cuando el Spinner se despliega. Sin esta línea, la lista usa el layout compacto y resulta difícil de tocar.
Pasos para crear un Spinner:
  1. Agregar <Spinner> al layout.
  2. Crear el arreglo de datos.
  3. Crear un ArrayAdapter con simple_spinner_item.
  4. Configurar setDropDownViewResource().
  5. Asignar el adapter al Spinner.
Ejercicio rápido: modifica el arreglo para mostrar países de Sudamérica: «🇵🇪 Perú», «🇨🇴 Colombia», «🇦🇷 Argentina», «🇨🇱 Chile».

4.2 Cargar el arreglo en la actividad

El layout de la Parte 3 se mantiene. Solo cambia el origen de los datos:

5. Eventos con OnItemSelectedListener

Es el listener propio del Spinner. Se activa cuando el usuario selecciona un ítem y exige implementar dos métodos:

Método Se ejecuta cuando…
onItemSelected() Se selecciona un ítem.
onNothingSelected() La selección desaparece (por ejemplo, el adapter queda vacío).
Parámetro de onItemSelected Significado
parent El Spinner (un AdapterView).
view La vista del ítem seleccionado.
position Posición del ítem: 0, 1, 2…
id Identificador de la fila.

5.1 Spinner con Toast

package com.example.spinnerlistrecycler

import android.os.Bundle
import android.view.View
import android.widget.AdapterView
import android.widget.ArrayAdapter
import android.widget.Spinner
import android.widget.TextView
import android.widget.Toast
import androidx.appcompat.app.AppCompatActivity

class SpinnerActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_spinner)

        val spinner = findViewById<Spinner>(R.id.spinner)
        val tvSeleccion = findViewById<TextView>(R.id.tvSeleccion)

        val paises = resources.getStringArray(R.array.lista_paises)

        val adapter = ArrayAdapter(
            this,
            android.R.layout.simple_spinner_item,
            paises
        )
        adapter.setDropDownViewResource(android.R.layout.simple_spinner_dropdown_item)
        spinner.adapter = adapter

        // Listener de selección
        spinner.onItemSelectedListener = object : AdapterView.OnItemSelectedListener {
            override fun onItemSelected(
                parent: AdapterView<*>?,
                view: View?,
                position: Int,
                id: Long
            ) {
                val paisSeleccionado = paises[position]
                tvSeleccion.text = "Selección: $paisSeleccionado"

                Toast.makeText(
                    this@SpinnerActivity,
                    "Seleccionaste: $paisSeleccionado",
                    Toast.LENGTH_SHORT
                ).show()
            }

            override fun onNothingSelected(parent: AdapterView<*>?) {
                tvSeleccion.text = "Selección: Ninguna"
            }
        }
    }
}
this@SpinnerActivity: dentro del object anónimo, this apunta al listener. Para obtener el contexto de la actividad se escribe this@SpinnerActivity.

5.2 Tres formas de obtener el ítem seleccionado

// Opción 1: desde el arreglo original
val item1 = paises[position]

// Opción 2: desde el parent (el Spinner)
val item2 = parent?.getItemAtPosition(position).toString()

// Opción 3: desde el adapter
val item3 = adapter.getItem(position)

5.3 Ignorar la selección automática inicial

onItemSelected() se ejecuta automáticamente al cargar el Spinner, con la posición 0. Si no quieres reaccionar a esa primera llamada, usa una bandera:

var primeraCarga = true

spinner.onItemSelectedListener = object : AdapterView.OnItemSelectedListener {
    override fun onItemSelected(parent: AdapterView<*>?, view: View?, position: Int, id: Long) {
        if (primeraCarga) {
            primeraCarga = false
            return
        }
        // Tu código aquí: solo se ejecuta cuando el usuario elige
        tvSeleccion.text = "Selección: ${paises[position]}"
    }

    override fun onNothingSelected(parent: AdapterView<*>?) {
    }
}
Ejercicio — Conversor de monedas: Spinner de moneda de origen (Soles, Dólares, Euros), un EditText con la cantidad, Spinner de moneda de destino y un TextView con el resultado.

package com.example.spinnerlistrecycler

import android.os.Bundle
import android.view.View
import android.widget.AdapterView
import android.widget.ArrayAdapter
import android.widget.ListView
import android.widget.Spinner
import android.widget.Toast
import androidx.appcompat.app.AppCompatActivity

class SpinnerActivity : AppCompatActivity() {

    private lateinit var spinnerCategoria: Spinner
    private lateinit var listView: ListView
    private lateinit var listAdapter: ArrayAdapter<String>

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_spinner)

        // 1. Referenciar las vistas
        spinnerCategoria = findViewById(R.id.spinnerCategoria)
        listView = findViewById(R.id.listView)

        // 2. Configurar el Spinner de categorías
        val categorias = resources.getStringArray(R.array.categorias)
        val spinnerAdapter = ArrayAdapter(
            this,
            android.R.layout.simple_spinner_item,
            categorias
        )
        spinnerAdapter.setDropDownViewResource(android.R.layout.simple_spinner_dropdown_item)
        spinnerCategoria.adapter = spinnerAdapter

        // 3. Filtrar el ListView según la categoría elegida
        spinnerCategoria.onItemSelectedListener = object : AdapterView.OnItemSelectedListener {
            override fun onItemSelected(
                parent: AdapterView<*>?,
                view: View?,
                position: Int,
                id: Long
            ) {
                actualizarListView(position)
            }

            override fun onNothingSelected(parent: AdapterView<*>?) {
                listView.adapter = null
            }
        }

        // 4. Clic en un producto del ListView
        listView.setOnItemClickListener { parent, _, position, _ ->
            val productoSeleccionado = parent.getItemAtPosition(position).toString()
            val categoriaActual = categorias[spinnerCategoria.selectedItemPosition]

            Toast.makeText(
                this,
                "Seleccionaste: $productoSeleccionado\nCategoría: $categoriaActual",
                Toast.LENGTH_SHORT
            ).show()
        }
    }

    // 5. Cargar los productos de la categoría seleccionada
    private fun actualizarListView(categoria: Int) {
        val productos = when (categoria) {
            0 -> {
                val frutas = resources.getStringArray(R.array.productos_frutas)
                val verduras = resources.getStringArray(R.array.productos_verduras)
                val carnes = resources.getStringArray(R.array.productos_carnes)
                frutas + verduras + carnes
            }
            1 -> resources.getStringArray(R.array.productos_frutas)
            2 -> resources.getStringArray(R.array.productos_verduras)
            3 -> resources.getStringArray(R.array.productos_carnes)
            else -> emptyArray()
        }

        listAdapter = ArrayAdapter(
            this,
            android.R.layout.simple_list_item_1,
            productos
        )
        listView.adapter = listAdapter
    }
}
Elemento Función
lateinit var Variables que se inicializan después, en onCreate().
actualizarListView() Separa la lógica de filtrado en una función propia.
when (categoria) Elige qué arreglo cargar según la posición del Spinner.
frutas + verduras + carnes Concatena los arreglos para la opción «Todos».
setOnItemClickListener Responde al clic en un producto del ListView.
Flujo: el usuario elige una categoría → onItemSelected() llama a actualizarListView() → se carga el arreglo correspondiente → el ListView se actualiza → al tocar un producto aparece un Toast.
Ejercicio avanzado — Biblioteca: Spinner con categorías de libros (Ficción, No ficción, Ciencia, Historia), ListView con los libros de la categoría y un AlertDialog con los detalles al tocar un libro.

package com.example.spinnerlistrecycler

import android.os.Bundle
import android.view.View
import android.widget.AdapterView
import android.widget.ArrayAdapter
import android.widget.Spinner
import android.widget.TextView
import androidx.appcompat.app.AppCompatActivity

class SpinnerActivity : AppCompatActivity() {

    private lateinit var spinnerPais: Spinner
    private lateinit var spinnerCiudad: Spinner
    private lateinit var tvUbicacion: TextView

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_spinner)

        // 1. Referenciar las vistas
        spinnerPais = findViewById(R.id.spinnerPais)
        spinnerCiudad = findViewById(R.id.spinnerCiudad)
        tvUbicacion = findViewById(R.id.tvUbicacion)

        // 2. Configurar el Spinner de países
        val paises = resources.getStringArray(R.array.paises)
        val paisAdapter = ArrayAdapter(
            this,
            android.R.layout.simple_spinner_item,
            paises
        )
        paisAdapter.setDropDownViewResource(android.R.layout.simple_spinner_dropdown_item)
        spinnerPais.adapter = paisAdapter

        // 3. Al cambiar de país se recargan las ciudades
        spinnerPais.onItemSelectedListener = object : AdapterView.OnItemSelectedListener {
            override fun onItemSelected(
                parent: AdapterView<*>?,
                view: View?,
                position: Int,
                id: Long
            ) {
                val ciudades = when (position) {
                    0 -> resources.getStringArray(R.array.ciudades_peru)
                    1 -> resources.getStringArray(R.array.ciudades_colombia)
                    else -> emptyArray()
                }

                val ciudadAdapter = ArrayAdapter(
                    this@SpinnerActivity,
                    android.R.layout.simple_spinner_item,
                    ciudades
                )
                ciudadAdapter.setDropDownViewResource(android.R.layout.simple_spinner_dropdown_item)
                spinnerCiudad.adapter = ciudadAdapter
            }

            override fun onNothingSelected(parent: AdapterView<*>?) {
                tvUbicacion.text = "Ubicación: -"
            }
        }

        // 4. Al elegir ciudad se muestra la ubicación completa
        spinnerCiudad.onItemSelectedListener = object : AdapterView.OnItemSelectedListener {
            override fun onItemSelected(
                parent: AdapterView<*>?,
                view: View?,
                position: Int,
                id: Long
            ) {
                val paisSeleccionado = spinnerPais.selectedItem.toString()
                val ciudadSeleccionada = parent?.getItemAtPosition(position).toString()

                tvUbicacion.text = "Ubicación: $ciudadSeleccionada, $paisSeleccionado"
            }

            override fun onNothingSelected(parent: AdapterView<*>?) {
                val paisSeleccionado = spinnerPais.selectedItem.toString()
                tvUbicacion.text = "Ubicación: $paisSeleccionado"
            }
        }
    }
}

Resultado al elegir Colombia y Medellín:

Ubicación: Medellín, 🇨🇴 Colombia
Cascada de eventos: cambiar país → se crea un nuevo adapter de ciudades → el Spinner de ciudades dispara onItemSelected() → se actualiza el TextView.
Primer evento: al abrir la actividad, onItemSelected() se ejecuta automáticamente en ambos Spinners con la posición 0. Es el comportamiento normal de Android.

8. Recordar la selección con SharedPreferences

Se amplía el ejemplo anterior para guardar el país y la ciudad elegidos. Al cerrar y volver a abrir la app, los Spinners muestran la última selección. El layout y los arreglos de la Parte 7 se mantienen.

package com.example.spinnerlistrecycler

import android.os.Bundle
import android.view.View
import android.widget.AdapterView
import android.widget.ArrayAdapter
import android.widget.Spinner
import android.widget.TextView
import androidx.appcompat.app.AppCompatActivity

class SpinnerActivity : AppCompatActivity() {

    private lateinit var spinnerPais: Spinner
    private lateinit var spinnerCiudad: Spinner
    private lateinit var tvUbicacion: TextView
    private var isFirstLoad = true  // Evita sobrescribir la ciudad en la carga inicial

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_spinner)

        // 1. Referenciar las vistas
        spinnerPais = findViewById(R.id.spinnerPais)
        spinnerCiudad = findViewById(R.id.spinnerCiudad)
        tvUbicacion = findViewById(R.id.tvUbicacion)

        // 2. Abrir el archivo de preferencias
        val prefs = getSharedPreferences("UbicacionPrefs", MODE_PRIVATE)

        // 3. Configurar el Spinner de países
        val paises = resources.getStringArray(R.array.paises)
        val paisAdapter = ArrayAdapter(
            this,
            android.R.layout.simple_spinner_item,
            paises
        )
        paisAdapter.setDropDownViewResource(android.R.layout.simple_spinner_dropdown_item)
        spinnerPais.adapter = paisAdapter

        // 4. Restaurar el país guardado
        val paisGuardado = prefs.getInt("pais_seleccionado", 0)
        spinnerPais.setSelection(paisGuardado)

        // 5. Listener del Spinner de países
        spinnerPais.onItemSelectedListener = object : AdapterView.OnItemSelectedListener {
            override fun onItemSelected(
                parent: AdapterView<*>?,
                view: View?,
                position: Int,
                id: Long
            ) {
                val ciudades = when (position) {
                    0 -> resources.getStringArray(R.array.ciudades_peru)
                    1 -> resources.getStringArray(R.array.ciudades_colombia)
                    else -> emptyArray()
                }

                val ciudadAdapter = ArrayAdapter(
                    this@SpinnerActivity,
                    android.R.layout.simple_spinner_item,
                    ciudades
                )
                ciudadAdapter.setDropDownViewResource(android.R.layout.simple_spinner_dropdown_item)
                spinnerCiudad.adapter = ciudadAdapter

                // Restaurar la ciudad guardada solo en la primera carga
                if (isFirstLoad) {
                    val ciudadGuardada = prefs.getInt("ciudad_seleccionada", 0)
                    spinnerCiudad.setSelection(ciudadGuardada)
                    isFirstLoad = false
                }

                // Guardar el país seleccionado
                prefs.edit().putInt("pais_seleccionado", position).apply()
            }

            override fun onNothingSelected(parent: AdapterView<*>?) {
                tvUbicacion.text = "Ubicación: -"
            }
        }

        // 6. Listener del Spinner de ciudades
        spinnerCiudad.onItemSelectedListener = object : AdapterView.OnItemSelectedListener {
            override fun onItemSelected(
                parent: AdapterView<*>?,
                view: View?,
                position: Int,
                id: Long
            ) {
                val paisSeleccionado = spinnerPais.selectedItem.toString()
                val ciudadSeleccionada = parent?.getItemAtPosition(position).toString()

                tvUbicacion.text = "Ubicación: $ciudadSeleccionada, $paisSeleccionado"

                // Guardar la ciudad seleccionada
                prefs.edit().putInt("ciudad_seleccionada", position).apply()
            }

            override fun onNothingSelected(parent: AdapterView<*>?) {
                val paisSeleccionado = spinnerPais.selectedItem.toString()
                tvUbicacion.text = "Ubicación: $paisSeleccionado"
            }
        }
    }
}
Instrucción Función
getSharedPreferences("UbicacionPrefs", MODE_PRIVATE) Crea o abre un archivo de preferencias privado de la app.
prefs.getInt("clave", 0) Lee un valor guardado; devuelve 0 si no existe.
prefs.edit().putInt("clave", valor).apply() Guarda un valor de forma asíncrona.
setSelection(posicion) Selecciona un ítem del Spinner desde el código.
isFirstLoad Bandera que restaura la ciudad solo al abrir la actividad.
Prueba: elige un país y una ciudad, cierra la app por completo y vuelve a abrirla. Los Spinners deben mostrar tu última selección.

9.2 Actividad

package com.example.spinnerlistrecycler

import android.os.Bundle
import android.widget.ArrayAdapter
import android.widget.Spinner
import androidx.appcompat.app.AppCompatActivity
import java.util.Calendar

class SpinnerActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_spinner)

        val spinnerAnio = findViewById<Spinner>(R.id.spinnerAnio)

        // Generar los años desde 1950 hasta el año actual
        val anioActual = Calendar.getInstance().get(Calendar.YEAR)
        val anios = (1950..anioActual).map { it.toString() }.toTypedArray()

        val adapter = ArrayAdapter(
            this,
            android.R.layout.simple_spinner_item,
            anios
        )
        adapter.setDropDownViewResource(android.R.layout.simple_spinner_dropdown_item)
        spinnerAnio.adapter = adapter

        // Seleccionar 2000 por defecto
        val posicion2000 = anios.indexOf("2000")
        spinnerAnio.setSelection(posicion2000)
    }
}

  • Spinner de género y Spinner de mes de nacimiento.
  • Spinner de año generado dinámicamente (1950 – año actual).
  • Botón «Registrar» que muestre todos los datos en un AlertDialog.
  • Guardar las selecciones con SharedPreferences.
